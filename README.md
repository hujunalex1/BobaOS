# 🧋 BobaOS (波波 OS) / CubePaw - Kids Cute Watch OS

> 专为 **Waveshare ESP32-S3-Touch-LCD-1.54** 打造的治愈系女童智能手表操作系统。
> **本项目基于优秀的开源项目 [雨墨 OS (Yumo OS)](./yumo-esp32-os) 进行二次开发与深度重构改造。**

---

## 🌟 核心特性与二次开发改造

本项目保留并致敬了 **雨墨 OS (Yumo OS)** 出色的底层硬件驱动与模块化应用架构，在此基础上进行了深度演进与儿童定制重构：

- 🍓 **原创「草莓波波摇摇乐」(Gravity Boba Jar) 物理引擎**：
  - **真实物理碰撞**：利用板载 **QMI8658 六轴陀螺仪**，6 颗萌系波波小球（草莓球、猫爪球、星星球、甜心球、香芋球、苏打球）随手腕倾斜自由滚落、碰撞、反弹。
  - **液体阻尼与微动**：模拟奶茶液体粘滞阻尼，平放在桌面时带有轻柔的水波微动，运动细腻丝滑。
  - **摇一摇与戳戳弹跳**：摇晃手表小球四处炸开，手指轻触屏幕小球立即欢快弹跳腾空。
  - **纯矢量微图标渲染**：顶部药丸标题左右带有纯矢量绘制的小草莓与小猫爪，彻底解决 GB2312 嵌入式字库缺失 Emoji 导致的乱码方块 `[ ]`。
- 🍬 **马卡龙糖果卡片 UI**：
  - 专为女童设计的高饱和糖果微徽章底托与 14px Q 弹圆角。
  - 纯净白色面板配合甜粉色细描边，告别传统工科仪表板的冰冷感。
- 📱 **流式双页桌面架构**：
  - **Page 0**：摇摇乐主交互玩具 + 3 个高频糖果大按键（小智 AI、小恐龙、萌芽物语）。
  - **Page 1**：左滑流畅过渡至双列糖果应用抽屉列表。
  - **底部指示栏**：带圆点切换指示，点击即可切换主屏/应用列表。
- ⚡ **全生命周期省电守护**：
  - 熄屏、切换应用或进入后台时，物理引擎与陀螺仪租约自动挂起，0 额外功耗。
- 🛠️ **精简开箱即用构建链**：
  - 剥离了臃肿的历史编译缓存，提供零环境依赖的直接烧录脚本与自动化构建脚本。

## 🛠️ 硬件配置

| 规格 | 参数 |
| :--- | :--- |
| **主控芯片** | ESP32-S3 (Dual Core Xtensa LX7 @ 240MHz) |
| **存储容量** | 16MB Flash + 8MB Octal PSRAM |
| **显示屏幕** | 1.54 英寸 ST7789V IPS LCD (240 × 240 分辨率) |
| **触摸控制** | CST816S 电容式单点触摸 |
| **重力传感器** | QMI8658 六轴 IMU (加速度计 + 陀螺仪) |
| **音频编码** | ES8311 DAC + 扬声器功放 |

## 🚀 快速上手：一键烧录已编译固件

如果你只需要将系统烧录到设备，无需配置复杂的 ESP-IDF 编译环境，仓库已内置了编译好的完整固件包：

```bash
# 1. 插入手表 USB-C 连接电脑，赋予脚本权限
chmod +x flash.sh

# 2. 自动检测端口并烧录
./flash.sh

# 也可以指定串口端口（例如：macOS）
./flash.sh /dev/cu.usbmodem2101
```

> 固件包文件：`yumo-kids-os-merged.bin`（约 5.9MB），包含了从 `0x0000` 开始的 Bootloader、分区表、OTA 数据及应用程序全部内容。

## 💻 源码编译 (Developer Build)

如果你需要自行修改代码并编译：

```bash
# 运行一键构建脚本（基于 ESP-IDF 5.4+ / 6.1 及 Ninja）
python3 scripts/build.py
```

构建脚本会自动完成以下步骤：
1. 增量或全新配置 CMake 工程
2. 调用 Ninja 进行并行编译
3. 自动合并生成最新的 `yumo-kids-os-merged.bin`
