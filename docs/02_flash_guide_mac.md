# Mac 电脑一键刷机与配网全流程

板子到手后，你只需要用 Mac 电脑通过 Chrome 或 Edge 浏览器即可完成**免安装编译链的「一键网页烧录」**。

---

## 阶段一：一键固件刷写（Web Flash 方式）

小智官方生态提供了极度方便的 Web 端烧录工具（基于 Web Serial API）：

1. **物理连接**：
   - 使用带数据传输功能的 Type-C 线将开发板连接至 Mac 的雷电/Type-C 接口。
2. **打开烧录工具页面**：
   - 在 Chrome 或 Edge 浏览器中访问小智开源烧录工具页：
     `https://xiaozhi.me/flash` 或小智开放平台设备接入工具。
3. **选择机型与固件**：
   - 硬件型号选择：`微雪 ESP32-S3 1.54寸 / Waveshare ESP32-S3 Box`（或对应的标准 1.54寸 ST7789 配置）。
4. **选择端口并烧录**：
   - 点击「连接设备 / Connect」，在浏览器弹出的端口列表中选中带有 `ESP32-S3` 或 `usbmodem` 字样的端口。
   - 点击「开始烧录 / Install」，保持连接约 1~2 分钟，进度条走完后板子会自动重启。

> **备用离线工具（如果使用 Python/命令行）**：
> 工作区已准备好可随时执行的脚本，如果你想用命令行，只需运行：
> ```bash
> pip install esptool
> esptool.py write_flash 0x0 <firmware_path>.bin
> ```

---

## 阶段二：首次 Wi-Fi 配网

刷机成功并重启后，屏幕上会出现配网提示：

1. **手机搜热点**：
   - 用手机在无线网络列表中找到名为 `Xiaozhi-XXXX` 或 `CubePaw-XXXX` 的 Wi-Fi 热点并连接。
2. **输入家里 Wi-Fi**：
   - 连接后手机通常会自动弹出配网网页（若未弹出，在手机浏览器打开 `192.168.4.1`）。
   - 在列表中选择家里的 2.4G Wi-Fi 并输入密码（注意：ESP32 系列芯片仅支持 2.4GHz Wi-Fi，不支持 5GHz 频段）。
3. **完成连接**：
   - 点击保存后，开发板会自动重启并联网。
   - 屏幕上会显示可爱的眼睛表情，并弹出一串 **6 位设备验证码**。

---

## 阶段三：云端绑定与后台管理

1. 打开电脑或手机浏览器，登录小智设备管理后台（例如 `https://xiaozhi.me`）。
2. 点击「添加设备」，输入屏幕上显示的 6 位验证码。
3. 绑定成功后，设备便正式激活！随时可以在后台更换模型、人设和音色。
