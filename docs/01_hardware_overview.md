# 硬件规格与特性速查：微雪 ESP32-S3 1.54寸 语音魔方开发板

## 1. 硬件核心参数

| 部件 | 规格参数 | 说明 / 对儿童体验的作用 |
| :--- | :--- | :--- |
| **主控芯片** | ESP32-S3 (Xtensa® 32-bit LX7 双核，主频最高 240MHz) | 自带高性能向量指令集，支持本地声音预处理与快速流式网络传输 |
| **无线通信** | 2.4 GHz Wi-Fi (802.11 b/g/n) + BLE 5.0 | 家用 Wi-Fi 低延迟传输语音流，BLE 辅助配网 |
| **显示屏幕** | 1.54 英寸 IPS 彩色 LCD，240 × 240 分辨率 | 262K 色彩，用于渲染生动灵动的大眼睛微表情与系统状态 |
| **显示驱动** | ST7789 系列驱动芯片 (SPI 接口) | 刷新率高、响应快，表情动画丝滑不卡顿 |
| **音频解码** | 专职音频编解码芯片 (Codec) + 板载 D 类数字功放 | 保证喇叭发音清亮柔和，不破音、不刺耳 |
| **麦克风** | 板载高灵敏度硅麦（MEMS 麦克风） | 灵敏拾音，支持降噪与回声消除处理 |
| **交互按键** | 物理轻触按键 | 儿童手感轻快明确，单击开始说话，再按立刻打断播报 |
| **供电与接口**| Type-C 接口 (支持充供电与固件数据传输) | 兼容手机/iPad 常见充电线，即插即用 |
| **存储扩展** | Micro-SD (TF) 卡槽 | 可选扩展本地儿歌或离线音频缓存 |

## 2. 硬件连接与到手注意事项

1. **数据线要求**：
   - 请务必准备一根**支持数据传输的 Type-C 数据线**（很多买手机送的仅供电线没有 D+/D- 数据芯，电脑将无法识别端口）。
2. **Mac 电脑端口识别**：
   - 插入 Mac 后，系统无需安装额外复杂驱动，ESP32-S3 的原生 USB CDC 端口会识别为 `/dev/cu.usbmodem*` 或 `/dev/cu.wchusbserial*`。
