# JoyCode ESP32-S3 port

Upstream: ducalex/retro-go, commit `4ced120669750ca7228fd0414211430c1d923166`, `retro-core/components/nofrendo`.
Original source file notices, COPYING and CREDITS are retained. COPYING contains GPL-2.0 text; individual Nofrendo file headers refer to GNU Library GPL v2. Preserve and review these original notices when redistributing.

Local adaptations: IDF component build, PSRAM allocation with checked failures, dynamically allocated memory/PPU/APU contexts, bounded shared iNES/basic NES2 loader, no database header overrides, reduced mapper registry, no disassembler/NSF/FDS frontends. A local frame-boundary checkpoint frontend now provides five manual save/load slots. CPU/PPU/APU architecture is retained, with mapper IRQ/audio and checkpoint hooks described below. Additional mapper files use the same pinned upstream commit; local changes reset per-game static state in maps 18, 21/25, 23, 32, 64 and 75, and correct Mapper206 CHR bank address/units. Small memory/PPU/APU contexts and the 4 KiB nametable use best-effort internal RAM (each <=4 KiB; a 96 KiB free-internal-heap threshold), falling back to PSRAM; all retain their existing free-on-shutdown paths. App drives one frame at a time, input/pacing/SD ownership belong to `main/core/fc_emulator.cpp`.

Supported mapper IDs (35): 0, 1, 2, 3, 4, 7, 9, 10, 11, 15, 16, 18, 21, 22, 23, 24, 25, 32, 33, 34, 64, 65, 66, 70, 71, 73, 74, 75, 78, 79, 87, 93, 94, 206, 245. No commercial game ROM is included. No ROM data is mapped from Flash.

The App and C engine share `nes/ines.h`. PRG+CHR payload is limited to 2 MiB, plus the 16-byte header and optional 512-byte trainer. Basic NES2 is restricted to submapper 0, supported console/timing and bounded RAM; unsupported layouts report a reason instead of being loaded inconsistently. Mapper24 now includes local VRC6 pulse/saw audio, banking/mirroring and instruction-boundary IRQ handling. Mapper74 adds mixed CHR ROM/2 KiB RAM; Mapper245 adds outer PRG selection and CHR RAM mapping. Mapper78 registration is corrected. MMC3 IRQ retains the existing scanline model; this is not a cycle-exact PPU/A12 emulator.

The local checkpoint codec serializes CPU/PPU/APU/mapper registers, RAM, input and video at a paused frame boundary. Pointer-bearing structures are not dumped: page mappings use checked region/offset references. ROM identity, layout, ABI, audio settings, CRC and all references are validated before loading live state. Mapper-specific checkpoint callbacks and missing reset state are included; this is a project-specific format, not a generic SNSS or cross-emulator format. File IO, five slots, SD generation checks and alternating records belong to `main/core/fc_saves.cpp` and `fc_save_store.c`. No automatic battery-SRAM persistence is provided.

These use synthetic ROMs on the host. The user accepted the prior FC changes; this does not establish exhaustive commercial-ROM, hardware frame-rate, audio or power-loss compatibility.
