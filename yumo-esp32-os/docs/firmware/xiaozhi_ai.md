# 小智 AI

更新至2026-11-02已烧录设备基线。小智是第25个应用中的第24项，设置仍在末位；通过Wi-Fi进行在线手动语音对话。

## 使用与小屏交互

先连接Wi-Fi，再进入小智AI。首次使用按页面提供的绑定信息在官方平台完成设备绑定。底部按钮按状态显示“连接 / 重试”“开始说话”“结束说话”或“打断”；聆听时说话，结束后等待回答，播放回答时可打断。离开应用会取消会话并释放资源，返回按钮在左上角。

顶部36px提供返回、应用名称和状态；正文232×148显示识别文本及回答，可以上下滚动；底部232×44为主要操作。正文使用15px阅读字体和自动换行，长内容优先占据屏幕，5套主题共用布局。无历史云端对话列表，页面不展示内部连接参数或密钥。

## 协议与资源

- `apps/xiaozhi.*` 负责界面；`core/xiaozhi_service.*` 负责会话、取消与音频资源所有权；`xiaozhi_cloud.*` 处理发现/绑定；`xiaozhi_transport.*` 和 `xiaozhi_protocol.*` 处理WebSocket及MQTT/UDP消息；`xiaozhi_audio.*` 处理麦克风与本机扬声器的Opus音频。
- 参考官方 `78/xiaozhi-esp32` 固定提交 `8dc6d4588368a2091bf4f577e8b03a491c28fd71` 的协议与绑定流程；保留 `firmware/main/core/xiaozhi.LICENSE` 的MIT版权和许可。该集成为雨墨系统内的适配应用，不替换整个系统。
- 音频依赖ESP Audio Codec 2.5.0；WebSocket 1.8.0与MQTT 1.1.0固定源码及校验见[依赖清单](../../config/dependencies.json)。使用现有麦克风/扬声器与共享音频资源管理，不增加耳机驱动。
- worker栈48KiB，放PSRAM并随会话释放；原8KiB在开始编码时曾发生栈溢出。日志记录打开、首次编/解码及退出栈余量，不记录语音、识别文本、回答或凭据。
- 录音、MP3、FC、8Bit音乐和游戏音频保留音频占用协调；退出、关屏及系统休眠按现有生命周期取消。没有新增后台唤醒或常驻对话。

手动对话为当前范围；唤醒词、AEC、MCP设备控制和官方OTA未启用。忽略的协议事件不能当作设备命令执行。
