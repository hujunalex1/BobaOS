# 下拉快捷设置

从屏幕顶边向下滑打开，从面板底部把手上滑关闭。240×240一页展示亮度、音量、Wi-Fi、蓝牙、重力、USB模式及睡眠；五种主题共用布局，只调整配色。面板不再显示“快捷设置”标题；亮度/音量使用图标，两条滑轨长138px，图标与屏幕边缘保留间距。

| 控件 | 行为 |
| --- | --- |
| 亮度 | 5%～100%，即时应用并使用原设置保存机制 |
| 音量 | 0%～100%，共用系统音量 |
| Wi-Fi / 蓝牙 | 开关无线，不代替选择网络/设备；显示真实开启、连接、切换或异常状态 |
| 重力 | 与设置共用运动/全屏旋转开关；关后锁定当前方向，FC还需开启游戏内开关 |
| USB | 在开发与烧录/SD读卡器间切换，确认和SD独占规则与设置一致 |
| 睡眠 | 弹出“仅熄屏 / 深度睡眠 / 取消”；仅熄屏保留App、PWR单击点亮，深睡结束App和无线、双击PWR重启 |

热点占用时 Wi-Fi 按钮不可操作，上游连接和共享由系统维护；USB、存储或音频忙时相关切换受限，失败会反馈。Wi-Fi 与蓝牙按现有启动策略尝试历史目标，系统运动默认关闭。USB 读卡器的手动深睡需先切回开发模式；暗屏自动深睡依供电与连接设置决定，并先完成 USB/SD 收尾。详见[电源管理](power_management.md)。

## 手势例外

| 场景 | 下拉面板 |
| --- | --- |
| 应用列表、设置、时钟、密码本、录音、文本、随机、万年历、蓝牙音乐、局域网等普通页面 | 可用；具体操作仍受任务忙状态限制 |
| 手电筒/SOS、蓝牙键鼠 | 禁用，避免干扰滑动调光、鼠标和键盘操作 |
| 相册 | 目录可用；看图、加载或失败的图片页禁用 |
| FC | 列表/蓝牙页可用；游戏运行或加载时禁用；暂停菜单可用，存读档忙时禁用 |
| 设计模式 | 模拟运行时禁用；其他页面按任务状态开放 |
| 摩斯电码 | 字典和未开始练习时可用；输入/转换和进行中的练习禁用 |
| 文件管理 | 无文件任务时可用，操作期间禁用 |
| 小恐龙、重力迷宫 | 运行禁用，暂停/菜单可用 |
| 开机遮罩、系统配对弹窗、展开的顶层下拉列表、关屏/深睡准备 | 不从背后打开面板 |

请从顶边开始下拉；文本正文中部的上下/左右滑动仍翻页。面板内拖亮度/音量不会被当成关闭手势，只有从底部把手开始的上滑才能关闭，避免无线和USB按钮操作被抢走。

面板覆盖期间触摸、外接键盘焦点和BOOT/KEY输入不会落到底下应用；返回优先关闭面板或其弹窗，PWR按原屏幕行为处理。关闭后恢复原输入会话，不补发旧分页/点击事件。

## 实现与验证

`main/ui/quick_panel.*`复用现有触摸数据与GUI泵，不新增I2C读任务；控件按打开创建、关闭销毁，按系统快照约250ms刷新，操作通过异步服务提交。App的`allowsQuickPanel()`声明场景限制。

宿主回归（历史开发记录未随源码分发）使用真实LVGL、生产面板代码和注入的硬件状态，覆盖995项及五主题100轮生命周期。已随当前固件烧录；实体手势与无线/USB互操作仍需要设备体验。完整构建记录见[当前状态](../current-state.md)。

全屏旋转与游戏方向锁定见[方向说明](screen_orientation.md)。重启恢复默认方向；重力迷宫及FC不绕过总开关。
