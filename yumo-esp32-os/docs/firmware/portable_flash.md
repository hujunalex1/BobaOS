# 便携系统升级包

适用：微雪 ESP32-S3-Touch-LCD-1.54，已经安装本项目且使用当前分区布局的设备。Windows 10/11 64 位可直接使用随包运行环境，无需安装 Python、ESP-IDF 或在线下载依赖。

## 使用

1. 将整个 ZIP 解压到任意可写目录。不要在压缩软件的预览窗口中直接运行，也不要只复制一个 CMD 文件。
2. 用支持数据传输的 USB 线连接设备的下载/串口接口，关闭占用该串口的投屏、串口监视器等程序。
3. 双击包内 `Flash.cmd`。只有一个匹配的 USB 串口时自动选择；多个候选时选择实际连接设备，不会静默选择第一项。
4. 等待固件校验、分区检查、系统写入和写后校验完成，成功后设备重启。过程中保持供电与数据线连接；若中断则停止，不会换串口或自动继续写入，重新运行时从检查开始。

脚本以自身所在目录寻找固件和工具，与命令窗口当前目录、盘符无关。未找到设备时，先更换数据线和 USB 接口；需要手动进入下载模式时，按住 BOOT，再按一下 RESET，随后松开 BOOT。进入下载模式后重新运行脚本。若电脑未安装所用 USB 转串口芯片的驱动，需要先安装该硬件对应驱动。

仅检查随包固件，不打开串口、不写设备：

```bat
Flash.cmd --dry-run
```

列出串口（不连接或复位设备）：

```bat
Flash.cmd --list-ports
```

多个串口时，也可以明确指定：

```bat
Flash.cmd --port COM7
```

实际使用自动识别出的串口号，不需要修改脚本。纯文件检查通过不代表设备已经烧录。

## 更新范围

仅写 `factory` 应用分区，偏移 `0x20000`，分区容量 `0x950000`。写入前核对包内镜像 SHA256、ESP32-S3 镜像头、大小、真实设备型号/容量与完整分区布局；设备表不匹配时停止，不自动迁移分区。

写入前后在设备端计算未擦写Flash区域的摘要，包括剩余系统分区尾部；摘要匹配后才自动重启。运行记录写在包内 `logs/`，不保存密码或原始Flash数据。

以下内容不写入：引导程序、分区表、NVS、OTA 状态、PHY、assets、vault、预留区及 SD 卡。因此已有设置、蓝牙配对和密码数据的存储区域会保留。包内 `partition-table.bin` **仅用于检查，绝不烧录**。

这是已有设备的系统升级包，不是空白板初始化包。它不提供整片擦除、强制覆盖或清空密码选项；设备的密码与服务同步身份保持原有构建配置。不要用其他身份构建的镜像替换包内文件。不要把本机身份固件当作通用公开版本分发。

## 文件

| 文件 | 用途 |
| --- | --- |
| `Flash.cmd` | Windows 双击入口 |
| `portable_flash.py` | 自动串口选择与系统升级检查 |
| `01_factory.bin` | 本次编译的应用固件 |
| `partition-table.bin` | 分区布局检查样本，只读 |
| `manifest.json` | 芯片、偏移、容量、固件哈希和编译状态 |
| `esptool.cfg` | 固定工具配置，避免受另一台电脑原有配置影响 |
| `runtime/` | 可搬迁的 Python 与烧录依赖 |
| `runtime-components.json`、`THIRD-PARTY-NOTICES.md` | 运行时版本及许可位置 |
| `SHA256SUMS` | 所有随包文件的完整性摘要 |

固件是否已经写入设备，以实际烧录结果为准；打包不代表烧录。SD 知识包、音乐和其他资源需要单独复制，本脚本不读写存储卡。
