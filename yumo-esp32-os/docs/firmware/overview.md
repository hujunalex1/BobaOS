# Yumo（雨墨）ESP32 OS

面向 ESP32-S3-Touch-LCD-1.54 的 240×240 小屏设备工程，使用 ESP-IDF、LVGL 和16MiB Flash。Yumo中文为“雨墨”，仅作命名说明，协议、蓝牙名称和部署密钥保持现值。

设备源码在工程根目录 `firmware/`，下载组件在 `dependencies/`，SDK与工具由使用者安装；不依赖旧工程的build或源码目录。

文档从[导航](../README.md)与[当前状态](../current-state.md)进入，维护约定见[贡献说明](../../CONTRIBUTING.md)。本次源码交付不包含旧运行记录。

## 常用操作

文本、相册目录首页左上角的返回键可退出APP；子目录返回上一级，阅读或看图时先返回文件列表。Wi-Fi扫描/已保存网络的详情名称为不可编辑文字；Wi-Fi手动名称/密码、热点名称/密码及密码本连接地址统一为36px高的可编辑输入框，共用系统键盘；键盘仍为两行各54px，展开后可滚动切换输入。

| 按键/场景 | 操作 |
| --- | --- |
| BOOT 单击 | 萌芽物语当前页返回（首页退出）；通常为音量减；文本中上一页，相册静态图缩小、GIF上一文件，随机普通模式开始、PK控制蓝方；FC游戏中为B（可按住） |
| KEY 单击 | 计时器开始/继续或记录；通常为音量加；文本中下一页，相册静态图放大、GIF下一文件，随机普通模式开始、PK控制红方；FC游戏中为A（可按住） |
| BOOT 双击 | 返回主界面；FC游戏页及游戏菜单中不退出 |
| KEY 双击 | 计时器内禁用；其他场景截图到SD screenshots目录；FC游戏按键接管区及相册图片查看页禁用 |
| PWR 单击 | 计时器运行时暂停、暂停时复位；文本阅读/加载页及图片查看页返回对应列表；其他页面亮屏/熄屏，普通关屏结束投放；已熄屏时优先唤醒；深睡单击不启动 |
| PWR 快速双击 | 深睡后唤醒重启，第二次按下检查窗口400ms；普通关屏仍单击亮屏 |
| PWR 长按 | 关机；电池断电路径仅电池供电时有效 |
| 设置中的安全弹出 SD 卡 | 等待保存、关闭文件并卸载；显示“可插拔SD卡”后再拔，插卡后点此按钮读取或到应用刷新 |
| 设置或快捷面板中的深度睡眠 | 保留RTC计时，停止无线和媒体等工作；唤醒后应用重新加载 |

文本、相册和随机打开期间BOOT/KEY不调音量，退出恢复。文本全屏阅读，左/上滑下一页，右/下滑上一页；翻页在屏幕中下部显示白字黑底页码1秒，再用0.5秒淡出。相册静态图可放大拖动，GIF全屏播放且不缩放，BOOT/KEY切同目录上一/下一GIF。两者内容页PWR返回文件列表，列表恢复亮灭屏，长按不变。随机普通模式两键均开始；石头剪刀布PK时BOOT控制左蓝方、KEY控制右红方，屏幕“开始”启动尚未开始的一方或双方，两方都有结果后只结算一次。详见[文本/相册/随机说明](reader_photo_random_20260921.md)。

FC整个应用也禁用音量，游戏中KEY=A、BOOT=B。下方三分之一区域左/中/右分别是Select/菜单/Start隐形触区；左上120×120触区内的半透明摇杆贴屏幕左上角，中心(33,33)、外圈直径66px、圆钮44px。系统运动许可开启后，游戏列表可开启本次App会话的重力控制；“存档/读取”提供三个手动槽及顶部独立自动槽，游戏实际运行满一分钟才首次自动保存。存档在SD卡nes目录，读档后需点击继续游戏。游戏页屏蔽BOOT双击退出。详见[FC操作](fc_touch_controls.md)及[存档说明](fc_saves.md)。

开机及深睡重启默认开启Wi-Fi和蓝牙：Wi-Fi尝试最近成功连接的网络，蓝牙选择最近配对的设备，走与雨墨“连接”按钮相同的流程。电脑/手机是否响应仍由对端决定；手动取消或断开后不抢连，省电关闭后不被后台反复打开。系统运动仍默认关闭。FC和迷宫需系统运动许可才能使用IMU，整个前台会话锁定屏幕方向；退出释放临时需求。普通熄屏后按时间逐级省电，明确的供电与连接保护开关优先。

从屏幕顶边向下滑可展开[快捷设置](quick_settings.md)，调整亮度/音量、无线/重力、USB模式及睡眠；从面板底部把手上滑关闭。手电、键鼠、图片查看和运行中的游戏等冲突场景禁用，游戏暂停菜单可用。

“设置→系统与电源→USB连接模式”支持[SD卡读卡器](usb_storage.md)。开机默认开发与烧录；读卡器模式由电脑独占SD，与电脑画面投放互斥。切回开发模式需先停止电脑复制，再在设备确认强制切换；设备不能替电脑刷新尚未发送的写缓存。

## SD卡目录

卡根目录直接放置以下内容，不需要 `joycode` 包装目录；设备挂载点为 `/sdcard`：

```text
config/
  vault.json       密码本同步地址
  nes-keys.json    FC键盘映射
recordings/        录音文件，由APP创建和管理
MP3/               *.mp3和同名.lrc/.LRC，仅扫描本层
chiptune/          *.chip.json小型乐谱，8Bit音乐实时合成播放
nes/               *.nes游戏、三个手动槽及独立自动槽ym-*.sav
txt/               建议的文本目录，也可浏览其他目录
pictures/          可选图片目录，JPG/JPEG/PNG/GIF也可放在其他可浏览目录
programming/       library.ykb知识包；state.bin由设备保存收藏/阅读记录
patterns/          lessons.ypg课程包；progress.dat由设备保存学习进度
garden/            garden-a.sav、garden-b.sav交替存档，更新模板时两份均保留
speedtest/         测速JSON历史，设备按需生成；更新模板时保留已有记录
screenshots/       KEY双击生成的PNG截图，按日期/时间/毫秒命名，可在相册查看
```

- [8Bit音乐](chiptune.md)：复制工程 `resources/sdcard/chiptune` 到SD卡根目录；包含4首公版主题的简化编曲和3首新创作，不含受保护的商业游戏或动漫音乐。
- [编程速查、设计模式资料与使用](learning_files_morse.md)：将本工程 `resources/sdcard/programming` 复制到SD根目录；设计模式内置课程可离线回退，SD保存进度。更新资料时保留用户 `state.bin` / `progress.dat`。
- 截图单次按需保存，正常完成后释放资源；照片加载/查看和FC游戏中禁用，PWR不变。详见[截图说明](screenshot.md)。
- 配置模板：[vault.json](../../resources/sdcard/config/vault.json)、[nes-keys.json](../../resources/sdcard/config/nes-keys.json)。修改模板后复制到SD卡对应目录。
- 密码本先使用本地地址同步，失败后提示并从 `config/vault.json` 尝试一次；只有同步成功才保存新地址。每次同步用服务端完整有效列表覆盖设备，包括删除和空列表。加密密码文件保存在独立vault分区。
- 文本读取保留前64KiB原始文件上限；翻页记忆自动写在TXT所在目录，文件名 `.yumo-read-<文件名标识>.bin`，每文件1024字节。无需手工创建，详见[阅读记忆](reader_photo_random_20260921.md)。
- 录音为16kHz、16bit、单声道WAV，使用双麦输入处理，以详细时间命名；暂停后可在同一文件继续。详见[当前录音布局](recorder_ui_dsp_20260919.md)和[录音处理说明](recorder_ui_dsp_20260919.md)。
- 拔卡前退出正在使用SD的App，到“设置→系统与电源→安全弹出 SD 卡”。成功后按钮变为“可插拔SD卡”；插回后需手动读取/刷新。卡槽仍为3.3V供电，软件不能断电或降压；不要在保存、卸载或读取过程中拔卡，详见[SD说明](sd_media_fc_20260918.md)。
- FC默认：方向键移动、Z=A、X=B、Enter=Start、Tab=Select、Space暂停、Esc回列表；按键可在配置中修改。支持范围与文件限制见[SD媒体与FC说明](sd_media_fc_20260918.md)。

## 密码本使用

设备管理员采用至少4个不同点的九点图形密码，服务网页管理员独立设置，两者不能混用。同步只需手动连接可访问服务的Wi-Fi；蓝牙用于向目标电脑输入，不是同步前提。每次同步完整覆盖设备列表，服务端删除或空列表也会同步；传输失败保留设备原库。密码存独立vault分区，最多256条/256KiB加密文件。

- 主分类页：同步、连接、超管；“修改密码”仅在主页，依次验证原图形和两遍新图形。
- 超管：验证设备图形密码后所有密码明文，按钮变蓝；再点退出。关屏、退出App或空闲锁定后失效。
- 工作：先选“单位 / 系统”，再选该组条目进入原账号/密码详情；应用：先选“应用名称 / 平台”，再选条目。空字段保留为“未填写”，同名按字段精确分组，不合并密码。
- 网页：先选账号，同行右侧为密码数量；进入后首行名称、第二行账号，随后显示各用途及密码。每行省略过长文字，账号和密码行末的“输入”直接发送，顶部回车单独发送。
- 眼睛：普通模式验证设备图形密码后只展示当前账号页密码，图标变蓝，再点隐藏、离页失效；超管模式下不可用。工作/应用普通密码保留单条详情与限时展示；其他分类去账号并持续显示码值。
- 蓝牙输入支持英文、数字及US ANSI复杂符号；不支持中文账号/密码，电脑布局影响实际输入。内容不会自动附加回车。

同步鉴权使用分别编入设备 `main/core/vault_deploy_key.hpp` 和Java `BuiltinSyncKey.java` 的独立密钥。更换它需双端重新编译、部署/烧录；不会改变已有密码文件和管理凭据的读取。原存储key、vault_id、salt及Bearer令牌保持不变，不能跟随同步密钥重建。请求/响应证明不匹配即拒绝，失败保留旧库；SD只提供地址。详见[同步机制与排错](vault_sync_20260920.md)。

## 本工程保留的旧独立密码服务

本节描述仓库自带的独立密码服务源码和脚本，使用自己的初始化身份与数据目录。当前设备可配置[公网HTTPS地址](vault_public_https_20261031.md)，无需为同步另开端口。

Spring Boot 2.7.18 / Java8，单Java进程与SQLite硬盘持久化。当前JAR是 `artifacts/server/joyvault.jar`，现用库是 `runtime/server/data/vault.db`，固定身份来自 `server/deployment/local-keys.json`。不需要Redis/MySQL，不设本机自启或自动备份。

在CMD中按需执行（四个独立操作）：

```bat
cd /d .\packaging\pc
Status-Local.cmd
Start-Local.cmd
Open-Local.cmd
Stop-Local.cmd
```

`Status`查询、`Start`启动、`Open`打开网页、`Stop`优雅停止，按需要选择，不必顺序全执行。构建入口是根目录 `Build-Server.cmd`，产物为 `artifacts/server/joyvault.jar`；本机启停脚本在 `packaging/pc`，运行数据保留在 `runtime/server`。

服务网页支持分类浏览、网页账号/用途分层、创建/编辑时生成推荐密码（默认16位、可选4～64位；大写、小写、数字、符号分别勾选，至少一种）。普通工作/应用/网页密码由超管再次验证服务管理员后，在列表、详情、编辑及导入预览明文，退出超管、锁定、登出或离开网页后失效。

网页分类独享Edge CSV导入：跳过空账号和不支持字符的记录，名称取账号、同账号密码合并、首个完整URL作为用途（已有主URL优先），后续域名最多取10字符，去重后逗号放入备注。单条备注最多256 UTF-8字节，多余部分截去；4096是CSV数据行上限。导入后按账号排序。全分类另支持加密 `.jyvault` 导出与去重合并导入，导入服务端与设备全量覆盖同步是不同操作。

[服务端README](../server/README.md) · [DX4600 Pro图形部署](../server/nas.md) · [设备密码本详细约束](password_vault.md)。NAS使用用户的 `eclipse-temurin:8-jre`，应用目录只读挂载 `/app`，独立硬盘数据目录读写挂载 `/data`，8443为HTTP端口。
