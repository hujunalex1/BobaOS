# SD 配置、录音机与 FC 游戏

适配ESP32-S3、240×240屏幕。当前说明涵盖SD安全弹出/刷新恢复、双麦录音、FC本机/重力控制、FC兼容范围及存读档。手动存档为三个槽，另有独立自动槽；详细规则以[存档说明](fc_saves.md)为准。准确产物和验证边界见[当前状态](../current-state.md)。

## 1. 准备 SD 卡

把工程 `resources/sdcard/` 内的 `config`、`recordings`、`nes` 三个目录复制到 SD 卡根目录。其他应用的目录见 [SD 卡说明](../../resources/sdcard/README.md)；需要ZIP时按[资源说明](../../resources/README.md)重新生成。该模板不含密码、密钥、游戏或录音。

```text
SD 卡根目录
├─ config
│  ├─ vault.json       密码本同步服务地址
│  └─ nes-keys.json    FC 键盘映射
├─ recordings         录音文件，由设备创建
└─ nes                .nes游戏；设备生成手动/自动存档
```

设备程序中的 SD 根路径为 `/sdcard`，所以配置完整路径是 `/sdcard/config/vault.json`。不要在卡上再套一层 `sdcard` 目录。程序不会格式化SD卡或自动删除已有文件；录音列表中仅在用户确认删除后删除选中的单条录音。

已有SD卡：把原 `joycode` 中的这三个目录移到卡根目录，合并时注意重名文件；应用不自动搬移旧文件、不再扫描旧路径。

### 安全拔出与重新插入

1. 退出录音、文本、相册或FC等使用SD的App，让文件保存和关闭完成。
2. 打开“设置→系统与电源”，点击位于“深度睡眠”上方的“安全弹出 SD 卡”。
3. 显示“正在安全弹出…”期间不要拔卡。系统阻止新的读写，等待已提交的保存、文件关闭及卡就绪，随后卸载文件系统并关闭SD信号输出。
4. 按钮变为“可插拔SD卡”后再拔卡。若提示保存/卸载失败或超时，按提示处理，不将失败当成功。
5. 插回卡后点“可插拔SD卡”读取，或到相应App点击刷新；挂载并读目录成功后，按钮恢复“安全弹出 SD 卡”。无卡/失败保留提示，下次手动重试。

卡槽没有接入可用的插卡检测信号，因此不自动检测重新插入。旧任务不会在弹出完成后自行重挂载；读写出错后的刷新会在全部句柄关闭后尝试恢复。App不后台运行，退出时仅完成必要文件收尾。

**卡槽仍供电：** SD VDD和外部上拉连接3.3V，没有独立的软件控电开关。安全弹出停止读写和总线驱动，不能降压或断电，也不能保证静电、异常接触或突然掉电不损坏卡。当前没有实物拔插/掉电验收记录。

## 2. 密码本同步配置

编辑 `config/vault.json`：

```json
{
  "schema": 1,
  "url": "http://vault.local:8443"
}
```

`url` 改为 NAS 或验证电脑的局域网地址和服务端口，只填服务根地址。不要填写 `localhost`、`127.0.0.1`、容器内部地址、网页路径、`/api/device/bundle` 或结尾斜线；设备的 localhost 是设备自身，不是 NAS。建议在路由器中固定 NAS 地址。此简化配置仅接受 HTTP，保留原有加密密码文件与两端内置密钥机制。

文件为 UTF-8 JSON（允许 UTF-8 BOM），最大 1KiB，只允许 `schema`、`url` 两个字段。密码、设备 PIN、管理员密码和密钥都不应写入这个文件。

同步流程：

1. 手动连接 Wi-Fi；解锁密码本，点击“同步”。不会自动打开 Wi-Fi。
2. 先使用设备当前保存的地址尝试同步。
3. 失败后提示“同步失败，尝试从SD卡获取配置后再同步”，读取 SD 配置，最多再尝试一次。
4. 配置读取失败或第二次同步失败，显示失败并停止；保留原地址与原密码库，不循环重试。
5. SD地址返回的加密文件必须通过库身份、解密、结构和容量校验；不比较列表版本。成功后以服务端完整有效列表覆盖（包括删除及空列表），并保存新地址；只有内容字节与地址都相同才避免重复写入。
6. 下一次同步先使用这个已验证的新地址。屏幕关闭、退出 App 或进入深睡会协作取消，不会继续后台同步。

本地地址仍可在原连接设置页手工修改。SD 回退不更改设备 PIN，不导入密钥，不清空密码库。

密码服务采用手动启停；验证同步前需要手动启动对应服务。NAS 容器部署时要发布服务端口，且电脑/NAS 防火墙允许局域网访问；手机或电脑能打开服务页面，是排查地址和端口的第一步。

## 3. 录音机

入口：应用列表 → “录音机”。顶部显示状态提醒，时间右侧是相隔5像素的音量条；下方是录音/停止控制和文件列表。

- 大录音键改为118×77，与右侧两排按钮上下端均对齐；计时数字缩至18px、列表增高6px；控制键统一大图标，开始/继续用实心圆，录音中用暂停符号。开始 → 暂停 → 继续，同一个文件续录；停止键完成保存。
- 点击文件播放；可快退、暂停/继续、快进、停止、返回或直接转录音。快进为2倍保调播放，快退为共用2KiB缓冲的2倍有声倒放；松开恢复此前播放/暂停状态，开头/末尾结束后清除按钮按压状态。播放时仅当前文件的删除键可用，确认后先停止并关闭文件再删除；刷新和其他文件操作暂禁用。
- 每条文件末尾的垃圾桶弹出确认，完整文件名可滚动，左侧确认、右侧取消，避免同位置连点误确认。固定路径/卡代次/大小/修改时间后提交，实际修改前再次核对；取消只关弹窗。刷新失败保留旧列表并禁用操作，未显示不等于被删除。删除后不能在App内恢复，详见[防误删说明](recorder_ui_dsp_20260919.md)。
- PWR关屏暂停、清除快进/快退状态；退出App停止并收尾，不后台录音。前台活动时避免自动息屏，暂停后恢复系统超时。

双麦独立处理，只有正相关、能量接近且无削波的信号才混合，否则稳定择路；之后通过SpeexDSP保守降噪和有界增益，补偿首尾帧延迟。详细界面、资源和验证边界见 [录音机新版说明](recorder_ui_dsp_20260919.md)。

文件仍为16kHz/16bit/mono PCM WAV，约1.92MB/分钟，保存在`recordings/年月日_时分秒_毫秒_序号.wav`。时间早于2024年会拒绝录音；不要录音时拔卡。写入中使用`.wav.part`并约每秒同步，正常停止才改名；异常断电仍可能损坏文件，不保证自动恢复。列表最多256个文件，不是通用MP3播放器。旧文件不会重新降噪或改写。

## 4. FC 游戏

把游戏文件放入 `nes/`，入口：应用列表 → “FC游戏”。不含 ROM，请自行放入有权使用的游戏。

可以直接选择游戏，无需连接蓝牙；KEY=A、BOOT=B，左上固定半透明摇杆控制方向，下方左/中/右隐形触区分别为Select、游戏菜单、Start。详见[本机控制说明](fc_touch_controls.md)。如需键盘，可在FC内的“蓝牙键盘设置”手动连接外接BLE键盘。设备仍然只允许一个蓝牙连接：外接键盘与“蓝牙键鼠/密码本向电脑输入”的连接互斥，App不自动扫描或回连。

默认键位：

| 键盘 | FC 操作 |
| --- | --- |
| ↑ ↓ ← → | 方向 |
| Z | A |
| X | B |
| Enter | Start |
| Tab | Select |
| Space | 暂停/继续 |
| Escape | 停止游戏，返回游戏列表 |

点击下方中间区域暂停并打开菜单，可继续、存档/读取、返回列表或退出应用。整个FC应用禁用音量；游戏中BOOT双击不会退出，方向滑动也不会触发系统返回。蓝牙断开清空旧输入后可继续使用本机控制，键盘与摇杆方向冲突时键盘优先。PWR关屏暂停并释放按键，亮屏后手动继续。运行中的游戏保持屏幕活动，不会因为长时间未触摸而自动息屏。

画面按1:1像素居中输出240×240，原帧左右各裁8列，保留全部240行；无缩放混色，边缘HUD可能裁切。保留半速显示的奇偶相位切换及有界抖动，PAL/NTSC模拟目标50/60Hz，显示发布上限25/30fps，不是实测帧率。转换更轻，但每帧传输像素增多约6.7%，详细验证与取舍见[FC画面输出](fc_rendering.md)。

### 重力方向和存档

游戏列表顶部手动开启重力方向，本次App会话有效；必须同时开启系统运动开关，FC不能绕过总开关，且不修改系统偏好。以水平为中立，斜向产生两方向，摇杆反馈最终输入；暂停、存读档、回列表、关屏或退出释放临时需求。具体优先级和按键见[控制说明](fc_touch_controls.md)。

暂停菜单“存档/读取”顶部为独立自动槽，下方1～3号为手动槽，底部并列“存档”“读档”。自动槽只允许读取，游戏运行累计一分钟后自动保存；手动空白槽直接保存，覆盖先确认。有效记录才能读取，成功回暂停菜单，点击继续后恢复。时间取设备时钟，时长按模拟帧计算。手动档为 `/nes/ym-<ROM SHA256>-<1..3>-<a|b>.sav`，自动档编号部分为 `auto`；a/b为内部交替代次，不应当作缓存删除。正常退出等待已发起的自动写入，详细操作和限制见[存档说明](fc_saves.md)。

### 修改键位

编辑 `config/nes-keys.json`：

```json
{
  "schema": 1,
  "keys": {
    "a": "Z",
    "b": "X",
    "select": "Tab",
    "start": "Enter",
    "up": "Up",
    "down": "Down",
    "left": "Left",
    "right": "Right",
    "pause": "Space",
    "exit": "Escape"
  }
}
```

支持字母A–Z、数字0–9、Up/Down/Left/Right、Enter、Tab、Space、Escape（或Esc）、Backspace、F1–F12，大小写不敏感。可以只填写部分操作，未填写的保持默认，但最终十个操作不能重复占用同一个键。暂不支持 Ctrl+Z 这类组合映射。

文件为 UTF-8 JSON，最大2KiB。缺文件用默认；格式、字段、按键或重复映射错误时整体使用默认，并在暂停页面提示。每次打开游戏重新读取；修改后退出游戏并重新打开即可，不用重新编译。

### 当前支持边界

- 单层游戏目录，最多列表256个 `.nes` 文件；PRG+CHR内容≤2MiB，文件上限额外允许16字节头和512字节trainer。
- 支持iNES 1.0和基础NES2（submapper必须为0），当前35种Mapper：`0、1、2、3、4、7、9、10、11、15、16、18、21、22、23、24、25、32、33、34、64、65、66、70、71、73、74、75、78、79、87、93、94、206、245`。已知DiskDude污染旧头可兼容。
- NES2仅普通大小计数和允许的NTSC/PAL/双区设置；PRG-RAM与CHR-RAM各总计≤8KiB，混合CHR-ROM/RAM仅允许Mapper74所需的最多2KiB CHR-RAM；不支持其他混合布局、指数大小、Dendy或额外硬件。不支持FDS、NSF、ZIP直接加载；遇到不支持的Mapper/子型号/容量等显示原因。
- Mapper24已补齐VRC6银行/镜像/IRQ和扩展音频，74/245已加入MMC3变种支持，78注册编号已修正。仍保留现有核心时序边界，详见[兼容说明](photo_fc_compatibility.md)，不能保证所有登记编号下的ROM均已兼容。
- 支持3个手动存档槽和独立自动存档（含当时RAM）；游戏实际运行满一分钟后开始周期自动存档，最后不足一分钟的进度可手动保存。下次打开同一ROM后可选择读档，详见[FC存档](fc_saves.md)。存档为当前核心专用格式，不保证其他模拟器或改变核心布局后的固件兼容。
- App 和核心工作任务按需创建；退出协作停止并释放 ROM、画面和工作内存。系统蓝牙协议栈按系统生命周期保留；音频流结束释放codec/I2S/DMA，共享I2C不卸载，下次按需重建。
- 模拟器来源、固定提交和许可证说明见 `components/nofrendo/PORT.md`；保留原始版权、COPYING和CREDITS。


本页路径以工程根目录下的 `firmware/` 为起点。本文说明现有行为；构建、设备和服务状态以[项目当前状态](../current-state.md)为准。

## USB读卡器

“设置→系统与电源→USB连接模式”可将SD作为电脑磁盘使用。切入前结束SD任务，电脑独占期间本机无法读写SD；切回开发模式先停止电脑复制、再在设备确认强制断开，不必等待电脑弹出指令。详细流程、互斥关系及写缓存限制见[USB读卡器](usb_storage.md)。

MP3音乐只读取SD根`/MP3/`的单层MP3与同名LRC，独立播放页和资源规则见[MP3音乐](mp3_music.md)。蓝牙手柄C/H模式分工及连接后隐藏摇杆见[FC操作](fc_touch_controls.md)。
