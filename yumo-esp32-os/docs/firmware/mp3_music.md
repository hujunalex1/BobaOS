# MP3音乐

更新至2026-10-22已烧录固件。进入应用直接显示播放页，默认定位上次成功播放的文件；文件不存在时回到首曲，不恢复播放进度。

## SD文件与格式

在SD卡根目录自行创建`MP3/`，放入`*.mp3`，只扫描这一层，不递归子目录，最多512曲。单文件上限512MiB；这是输入边界，不保证所有达到边界的文件都能播放。

解码使用minimp3，支持MPEG-1/2/2.5 Layer III、CBR/VBR、8–48kHz、单声道或双声道；AAC、WMA、MP4和MPEG Layer I/II不在范围内。文件中途采样率/声道变化会拒绝继续解码。

同目录同名`.lrc`或`.LRC`用于歌词，单份最多128KiB、1500行，支持多时间戳和offset；无歌词时显示音乐文件名。歌词文本解码复用现有文本解码工具。

## 播放页

无标题栏和退出按钮，歌词直接占据主体：前一行、当前行、后一行，当前行使用22px字库及两行区域，长文字滚动。下方为细进度条/时间、播放暂停、上一曲/下一曲、单曲循环和列表。没有文件时在主内容区提示“SD /MP3 中没有音乐”。BOOT双击沿用系统退出。

## 音频与资源

SD读取/解码与扬声器输出分任务，使用32块PCM队列、24块启动预缓存；短暂等待有界，音频锁释放后让出一个tick。解码索引单次分配预算2MiB，避免无界占用内存。切歌、退出、关屏/深睡及SD/USB独占转换按现有生命周期协调，退出不在后台播放。

当前输出为本机扬声器。Type-C耳机的UAC驱动及切换逻辑已按用户要求撤回；USB读卡器、投屏与开发串口继续保留。蓝牙音乐App是对另一台设备的媒体遥控，不是本机MP3的A2DP音频输出。

## 源码、许可与验证

应用在`firmware/main/apps/mp3_music.*`，播放服务与模型在`firmware/main/core/mp3_player.*`与`mp3_model.hpp`，解码组件在`firmware/components/mp3_decoder/`。组件保留minimp3源码及CC0许可，固定上游`lieff/minimp3`提交`ea99364f61c14656440e8d77e9c233ccf3124633`，构建使用`MINIMP3_NO_STDIO`、`MINIMP3_ONLY_MP3`、`MINIMP3_NO_SIMD`和`-O2`。

配套检查包含解码、worker、真实LVGL播放页、快捷面板和系统收尾回放；来源构建与烧录见[当前状态](../current-state.md)。这些结果不代替长时间实机听感、任意MP3兼容性或SD卡性能测试。普通编译复用现有C字库；重新生成音乐字库时需自行提供有授权的字体文件。
