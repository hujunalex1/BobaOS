# 电源、自动熄屏与休眠

既有省电策略保留在 2026-10-14 已烧录版本中，本页补充电量显示和休眠时钟自学习。产物来源和验证范围见[当前状态](../current-state.md)。屏幕关闭、低负载运行和深度睡眠是不同状态。

## 默认策略

下表以已确认电池供电、自动休眠开启且没有连接保护阻止深睡为前提。启动初期暂按插电保护；连续30秒无外电信号后自动恢复省电，详见供电判断。

| 场景 | 默认行为 |
| --- | --- |
| 普通页面无操作 | 60秒后自动熄屏 |
| 文本内容阅读、时钟、点亮的手电筒/SOS | 保持亮屏，60秒无操作后进入低负载运行 |
| 阅读/时钟低负载 | 省电亮度15%，不会超过用户原亮度；真实操作后恢复 |
| 手电筒/SOS低负载 | 保留当前亮度和闪烁节奏 |
| 熄屏后120秒 | 自动进入省电待机，按门闩条件允许Modem-sleep及自动Light-sleep |
| 熄屏累计240秒 | 自动进入Deep-sleep；不是在前一步后再等240秒 |

亮屏时只把真实触摸、按键等作为操作，时钟走秒或界面刷新不延长空闲计时。进入熄屏计时后，后台录音、播放、游戏、热点、同步及场景提示变化不会推迟期限；到期先发起系统收尾，再等待文件与外设安全结束，不强杀写盘任务。

明确设置优先：关闭自动休眠则不执行熄屏待机/深睡，关闭某阶段时间则禁用该阶段；插电休眠保护同时禁止待机和深睡，连接保护仅禁止深睡。解除插电保护或重新开启自动休眠后，从解除时刻重新等待；连接保护解除后仅重排深睡计时，不重置已经允许的待机。无关设置及未使权限变化的供电状态变化不重置暗屏期限。

文本/时钟/手电/SOS保持亮屏期间不会走“熄屏后深睡”的计时链。关屏后则按该链处理；手电关屏停止SOS。最长续航不是保证固定续航小时数，实际电流、无线连接与电池状态仍需实测。

## 设置入口

“设置→显示与声音”可调自动熄屏时间、常亮省电等待时间、省电亮度，以及“接通电源时熄屏”。

“设置→系统与电源”可调自动休眠、熄屏待机/深睡等待时间、常亮省电策略、“连接时禁止深睡”及“接通电源时休眠”。时间配置保存到本机；旧版省电设置会保留，新增两项插电开关默认关闭。设置页按滑块、开关、其他操作、说明文字排序。

“最长续航”允许在常亮低负载阶段关闭闲置Wi-Fi/蓝牙；“保持连接”不主动关闭无线。“连接时禁止深睡”默认关闭，开启后实际Wi-Fi或BLE连接会阻止自动深睡，也阻止最长续航策略主动关无线；不阻止自动熄屏/待机，不限制用户手动深睡。后台忙任务仍限制强制轻睡和提前关闭无线，但不延长暗屏的自动深睡期限。

## 插电时的两项独立开关

| 选项 | 默认 | 关闭时且供电受保护 |
| --- | --- | --- |
| 接通电源时熄屏 | 关闭 | 不自动熄屏；已被自动策略熄灭的屏幕恢复显示 |
| 接通电源时休眠 | 关闭 | 不进入自动低负载/降亮度、自动轻睡、熄屏省电待机或自动深睡；不为续航主动关无线 |

两项互不代替：可以允许自动熄屏但禁止自动休眠，反之亦然。插电休眠保护时保留CPU性能锁，Wi-Fi策略允许时使用`WIFI_PS_NONE`；允许省电时可使用`WIFI_PS_MIN_MODEM`。不会为了切换策略重新连接网络。

这两个开关针对自动行为，手动PWR亮灭屏、手动深睡、长按关机仍可使用。不会因插电保护自动点亮用户手动关闭的屏幕，也不会打断USB投放。自动深睡在发起、锁内提交、worker收尾入口及关闭外设后都会复核相关设置；插电保护、连接保护、关闭自动休眠或关闭深睡阶段会取消尚未进入终态的自动请求。

## 供电识别与手动确认

本板没有独立VBUS检测脚。GPIO3充电信号为低只能证明正在充电；变高无法区分满电、拔线和无电池。USB串口/JTAG在线信号只能辅助识别正在通信的电脑，普通充电器不提供该信号。固件不使用电量百分比或电压猜测是否插电。

每次启动先暂按插电保护。连续30秒没有充电或USB在线信号后，自动进入“无外电信号，按电池省电”，无需每次手动确认；之后按照设置执行待机和深睡。已熄屏时保护解除会重新开始相应等待时间。

检测到充电或USB在线，立即恢复外电判定，遵守“接通电源时熄屏/休眠”开关。信号再次消失后重新观察30秒，不用过期采样推断电池供电。采样中断超过3秒暂按未知保护并重新观察。

“已拔电，恢复省电”仍允许在无信号稳定2秒后提前确认；“恢复插电保护”会保持本次手动保护，不会30秒后自动取消。用户重新确认电池或检测到真实外电后进入下一轮判断；重启默认重新观察。

满电普通充电器可能没有充电或USB在线信号，因此优先续航方案也可能在仍插线时自动休眠。这是用户确认的取舍，可手动恢复插电保护；不宣称能完整检测VBUS。

## 手动熄屏与深睡唤醒

PWR通常单击亮灭屏，普通熄屏保留应用和已建立链路。文本阅读/加载与相册图片页中，亮屏时PWR先返回文件列表；已熄屏时单击优先亮屏。

独立“深度睡眠”应用已移除；可从设置→系统与电源，或下拉快捷面板→睡眠进入，确认后使用同一系统收尾流程。深睡保存时钟/偏好、结束应用及媒体、停止无线、完成SD/截图/投放收尾后关闭外设，只保留RTC计时及唤醒条件。深睡不保留蓝牙或Wi-Fi连接。

深睡需要快速双击并松开PWR才启动；单击或超时继续深睡。当前第二次按下的检查窗口为400毫秒，从第一次松开通过20毫秒防抖后计算，按下/松开阶段另有350毫秒上限；不是允许几秒间隔的两次单击。窗口在源码`main/core/wake_click.h`中固定，尚无设置界面。

RTC唤醒检查会喂看门狗，避免多次被拒绝的单击累计触发复位而绕过双击判断；长按时等待松开再布防。唤醒后重新启动并播放开机动画，Wi-Fi和蓝牙默认开启并分别尝试最近成功网络、最近配对设备，系统运动许可默认关闭。最新启动核验通过，但双击手感、满电充电器插拔与长期功耗没有新的实机量化验收。

## 实现与维护

策略在`power_policy.hpp`/`power_runtime.cpp`；供电判定在`supply_policy.hpp`与`battery_mgr.*`，自动/手动收尾在`power_mgr.*`，双击检查在`deep_sleep_wake.c`/`wake_click.h`。NVS优先读写`power_v2`，兼容读取`power_v1`，不擦除旧偏好或密码数据。

CPU按任务锁在240～40MHz间动态调整；BSP使用RC_FAST背光PWM，静态亮屏在门闩允许时自动轻睡，触摸/按键唤醒，LVGL使用单调时间。低负载服务空闲轮询1秒，通常50毫秒，通知立即唤醒。电量ADC维持亮屏5秒/暗屏15秒采样；供电信号由独立的`Battery::pollSupply()`共享限频更新，自动策略也会调用，避免慢I/O阻塞worker导致供电确认过期。这里仅读取充电GPIO及缓存USB状态，ADC仍在worker中。USB投放仍保持逻辑亮屏、性能与输入，不把只关背光视为普通休眠。

2026-09-30修复了两类干扰省电的问题：供电状态更新被慢任务拖延，以及触摸中断/失败读取被当作用户活动。现在中断只请求读取，有效按下、移动、松开才记录活动，I2C失败不续期；空闲判定前预读并缓存触摸结果。亮屏时允许触摸GPIO轻睡唤醒，暗屏时关闭该唤醒源，按键唤醒保持，避免触摸信号使暗屏设备反复唤醒。

网络校时等待真实回复时有短时忙标记，完整尝试最多约一分钟；成功、超时、断网、深睡中断均释放。它不会自动点亮屏幕，也不延长暗屏深睡期限，详见[网络校时](network_time.md)。8Bit音乐、录音等在亮屏时保留各自会话提示，暗屏自动深睡到期后统一结束应用并释放资源。

2026-10-02回归包含43,996项实际供电采样/策略检查、30,377项触摸/唤醒检查和638项电源运行时检查。覆盖无手动确认的整夜模拟、插电开关组合、采样中断和手动保护；仍未进行实际整夜续航测量。

电量曲线仍按用户指定4110mV显示100%，不代表硬件充电阈值或精确SOC。电量与硬件边界见[硬件映射](hardware.md)。

## USB读卡器与游戏音频

读卡器开启或仍在切换/恢复时，亮屏下阻止自动低负载和自动熄屏，手动深睡/主题重启仍需先结束读卡器。PWR可手动仅熄屏；熄屏后若供电和连接设置允许，达到自动深睡时间会主动结束USB会话，停止接收新请求并等已接收写入完成。设备无法提交电脑尚未发出的缓存，请在电脑结束复制并弹出磁盘。默认“接通电源时休眠”关闭，因此通常接电脑时仍受保护。详见[USB读卡器](usb_storage.md)。

游戏音乐/音效仅实际输出时计入忙状态；暂停且无剩余音效后关闭codec，不因保留静音会话永久阻止自动睡眠。真正进入深睡时仍等待音频worker退出。普通启动默认开启蓝牙一次，之后省电关闭不会由轮询重开。

## 电量显示算法

2026-10-09 开发、并纳入 2026-10-12 已烧录版本的算法，继续用 ADC 电压估算电量，没有新增库仑计。针对前段掉电过慢、末段过快的显示问题，降低中段估值并重新分布曲线：

| 电压 | 曲线目标 |
| --- | --- |
| 3.30V | 0% |
| 3.60V | 10% |
| 3.70V | 18% |
| 3.80V | 40%（原为 55%） |
| 3.90V | 64% |
| 4.00V | 85% |
| 4.05V | 93% |
| 4.11V | 100% 端点 |

三次电压采样取中位数，再做时间滤波，抑制单次负载压降；显示保留小数进度并在既有 worker 更新，持续小幅变化能逐步反映，不再等待两分钟后集中跳动。充电与静置回升仍有限速和去抖；显示 100% 仍需既有稳定时间及非充电资格判断，不代表硬件充电截止或精确剩余容量。

亮屏 5 秒、暗屏 15 秒的 ADC 周期及供电识别规则不变。代码回放使用模拟电压轨迹，尚未采集本电池完整放电曲线，不能据此保证百分比与剩余使用时间线性对应。

休眠走时同时采用内部 RC_FAST/256，约增加 5μA 的芯片深睡电流估计，整机未实测；配置与验收方法见[网络校时](network_time.md)。

## 休眠时钟动态补偿（2026-10-14 已烧录）

启动 3000 周期校准之外，实际深睡执行器通过项目链接包装接管 SDK 最终测量，以 3×3000 周期中位数交回 SDK，避免被其短周期重校准覆盖。可靠的 RTC 记录跨被拒绝的单击保留；真正双击唤醒后在 UI 之前只补偿一次。

每次可信联网校时捕获修改前偏移；有效窗口累计深睡至少一小时且占间隔一半以上，动态更新系数并由 Settings 保存。手动改时/普通重启使观察窗口失效，已持久化系数保留。该功能不定时唤醒、不修改既有休眠时间或供电/连接优先级。精度分辨率、学习条件及长睡验收见[网络校时与自学习](network_time.md)。

测速的网络与存储任务纳入忙状态和深睡收尾，退出或休眠协作取消并等待释放，不强杀正在写盘的任务，也不推迟用户设置的暗屏深睡期限。

## 计时器与萌芽物语

[计时器](timer.md)在前台通过StayLit/KeepSession保持亮屏与会话，PWR单击用于暂停/复位；退出释放提示并恢复用户原有熄屏设置，不改全局偏好。[萌芽物语](garden.md)沿用普通省电规则，关屏暂停动画和记忆演示，唤醒重新倒计时；已开始的SD保存按存储收尾流程完成。
