# KEY双击截图

亮屏时双击KEY，当前画面保存为240×240 PNG，完成后显示保存提示。PWR没有增加截图功能，原有亮灭屏、内容页返回和长按行为保留。KEY单击仍按当前应用处理。

截图目录是SD卡根目录 `screenshots/`，不存在时由设备创建，不需要 `joycode/` 上级目录。示例文件名：

```text
screenshots/2026-09-24_17-45-08-123_00.png
```

名称依次包含设备日期、时分秒、毫秒与防重名序号；时间准确性取决于设备时钟。进入相册，从根目录打开screenshots即可查看。

计时器内KEY被接管用于开始/记录，KEY双击不截图，BOOT双击退出。FC游戏运行及接管游戏按键的暂停/存档菜单中禁用截图，KEY继续作为A键处理；相册查看、加载图片或显示图片错误时也禁用。退出图片页回目录后恢复。屏幕关闭、正在休眠、SD已安全弹出或已有截图任务时不启动新的截图；失败给出相应提示，不自动重挂载已弹出的SD。

实现位于 `main/core/screenshot.cpp` 和 `screenshot_png.c`。请求合并为一个任务，按需分配115,200字节RGB565帧缓冲；GUI采集完整帧后，单独短时任务编码并写SD。先写 `.png.part`，刷新、同步并关闭文件后重命名为PNG；错误时尝试删除未完成文件。正常写入结束释放任务和帧缓冲，不后台持续截屏。

已开始写盘的截图会先安全收尾，深睡/重启和SD弹出等待存储关闭；退出当前App不会强杀保存任务。断电或损坏卡仍可能留下未完成文件，不把文件收尾机制等同绝对掉电安全。

功能自2026-09-24交付后保留在当前固件中，版本及验证边界见[当前状态](../current-state.md)。
