# 全屏方向与重力感应

更新日期：2026-10-20。已随当前固件编译、烧录并通过启动检查，版本与验证范围见[当前状态](../current-state.md)。

## 使用

快捷菜单和“设置”中的重力感应开关控制同一状态。开启后，设备根据重力在默认、90°、180°、270°四个方向间切换，整个画面和触控坐标同步调整。关闭后保持当前方向；方向仅保存在内存，重启及深睡唤醒重启恢复默认方向，系统重力开关沿用开机默认关闭策略。

进入重力迷宫或FC应用即锁定当时方向，覆盖列表、菜单、暂停和游戏页面，退出应用后才恢复自动判断。两者的重力操作均以当前屏幕方向为准。系统重力开关关闭时，游戏也不能绕过开关借用传感器；FC仍有本次应用会话的重力开关，两个开关都开启后才产生重力方向输入。

| 情况 | 屏幕行为 |
| --- | --- |
| 开关开启、普通前台界面 | 倾斜至新方向并保持稳定后旋转 |
| 开关关闭 | 锁定当前方向 |
| 重力迷宫或FC前台 | 锁定进入应用时的方向 |
| 手指按住、滚动、待处理触摸或正在截图 | 暂缓旋转，结束后重新计稳定时间 |
| 平放、明显抖动、冲击、无效/过期读数 | 保持当前方向 |
| 关屏、低速空闲或准备深睡 | 暂停自动方向采样需求 |
| 重启 | 恢复默认方向 |

稳定检测窗口800ms，两次切换至少间隔1200ms；使用平滑、主轴阈值和滞回，避免边界来回跳转。屏幕平放时无法可靠判断朝向，因此不会为了轻微姿态变化而旋转。这里只提供四向切换，不提供任意角度连续旋转。

## 实现与维护

ST7789显示驱动统一设置轴交换、镜像和面板偏移；LVGL始终保持240×240逻辑画布及零逻辑旋转。触摸驱动只做一次逆坐标映射；重力游戏使用同一方向映射加速度。时钟已经移除独立IMU读取、局部字形旋转和方向状态，所有表盘随系统画面一起旋转。

系统worker读取QMI8658，GUI只读取有效期250ms的缓存；开关、休眠及应用锁定复用现有资源生命周期。显示参数更新成功后才发布新触控方向，失败尝试恢复旧参数。截图和USB投屏仍输出正向240×240逻辑画面，无需取消其LVGL零旋转检查。

主要入口：`core/screen_orientation.*`、`core/orientation_model.hpp`、`core/qmi8658.*`、板级`bsp/orientation.h`及显示驱动。新增使用重力操作的App应覆盖`locksScreenOrientation()`，并在处理加速度前调用统一坐标映射。

## 验证边界

来源固件774项源码检查、43个目标编译器模型和3项防护通过；四区烧录校验、30秒启动及原数据保持检查通过。方向宿主回放执行461,056项断言，覆盖240×240全部像素的四向映射、回滚、触摸/截图/休眠延迟、开关、应用锁定及游戏坐标。

宿主模拟不等于真实面板与IMU验收。仍需实际测试四个持机方向的显示、边角触控、关开开关、重力游戏手感与重启方向；本次没有新的长期功耗测量。
