# 8Bit音乐

“8Bit音乐”在蓝牙音乐之后、随机之前。它读取SD卡上的小型乐谱，在设备端实时合成声音；与蓝牙音乐的媒体遥控功能分开，不需要蓝牙连接。

## 复制资源与播放

将本工程sdcard/chiptune（历史开发记录未随源码分发）整个目录复制到SD卡根目录，得到 `/chiptune/*.chip.json`，无需`joycode`包装目录。打开应用后点击刷新，选择曲目开始播放；首次进入不自动播放。

列表每页4首，可前后翻页。播放页提供上一曲、下一曲、暂停/继续、停止、音量和单曲循环。停止将位置归零；返回曲目列表仍可继续播放，退出App则停止并释放资源。普通熄屏仍播放；刷新会停止当前曲目并重新读取目录。错误条目标记“!”，点入可查看原因。

资源包含卡农、欢乐颂、小星星、货郎的简化芯片风格编曲，以及3首项目新创作短曲。没有附带商业录音或受保护的游戏、宫崎骏动漫主题曲。曲目来源、项目编曲的使用说明及具体文件见[曲目与使用说明](../../resources/sdcard/chiptune/曲目与使用说明.txt)。全部示例初始开启循环，可在播放页关闭。

## 格式与容量

| 项目 | 当前范围 |
| --- | --- |
| 文件 | UTF-8 JSON，扩展名`.chip.json`，`format=chip-score`、`version=1` |
| 目录 | 仅扫描`/chiptune`第一层，按文件名排序；最多200首、检查4096个目录项，超限显示“已截断” |
| 单首 | 最多64KiB、2048个事件、单轮10分钟 |
| 速度 | `tempo`为40～240整数 |
| 音轨 | 最多2条pulse、1条triangle、1条percussion，共4轨 |
| 输出 | 22050Hz、16bit、单声道实时PCM合成 |

音符支持C～B、升降半音、休止、O2～O6八度、长短时值和单附点；打击轨使用K/S/H表示底鼓、军鼓和踩镲。具体语法及示例在资源说明中。不支持直接播放MP3、MIDI、NSF、游戏ROM或任意MML方言，不能通过改扩展名转换。

## 资源与省电

目录扫描及播放器分别按需启动6KiB PSRAM栈任务，解析有界乐谱；播放时以256采样块实时输出，不预生成整曲PCM。加载完后关闭SD文件，切歌/刷新才再次读卡。音频与录音、FC、游戏合成声音互斥。

亮屏播放/读取期间有忙保护；暗屏后按显式设置和期限发起休眠，不因音乐持续播放而延期。暂停或停止淡出后关闭音频流；静止期间保留当前App需要的乐谱，退出协作结束任务、释放乐谱/列表/音频。深睡等待退出收尾。已加载歌曲不占用SD文件会话，不等于可以绕过安全弹出流程。

代码入口为`main/apps/chiptune.*`、`main/core/chiptune_player.*`、`main/core/chiptune_score.*`。首次交付见烧录记录（历史开发记录未随源码分发），已包含在[当前固件](../current-state.md)。现有验证覆盖协议、合成PCM、任务生命周期和UI；喇叭音色、响度及长期播放功耗尚未实机量化。
