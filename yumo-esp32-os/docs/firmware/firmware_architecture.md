# 当前固件架构

本页路径以工程根目录下的 `firmware/` 为起点。本文说明现有行为；构建、设备和服务状态以[项目当前状态](../current-state.md)为准。

`main/apps`注册25个应用（用户顺序可保存，设置最后），主编译清单以 `main/CMakeLists.txt` 为准；`main/core`负责系统服务、无线、输入、存储、电源及音频，`main/ui`负责界面和字体。`components`为本地组件和BSP，`managed_components`为依赖锁定的第三方组件。

## 应用、线程与资源

应用注册表保存工厂，打开时创建当前App；退出时撤销输入和订阅、停止定时器、结束应用任务、删除界面并释放实例。没有App预加载或隐藏常驻实例。底层存储和音频I/O需安全收尾，不能强杀持锁任务。

LVGL线程负责界面和应用导航，通过命令及状态快照与系统服务交互。无线异步回调不持有已销毁的App界面；会话代次用于拒绝取消或退出后的旧结果。系统无线栈资源按系统生命周期管理，不等于后台App。

## 无线、存储和电源

BLE连接由SystemService独占的`BluetoothConnectionFlow`统一管理，应用提交值请求。用户切换已保存设备时，先结束旧连接、等待真实GAP收尾，再邀请指定目标；发现/取消UI独立于瞬时无线状态。CONNECT与ENC_CHANGE共用安全完成入口，处理加密先于连接通知的顺序，rc=7不再误判为安全失败。操作和实测边界见[蓝牙连接](bluetooth_connections.md)。

Wi-Fi和蓝牙开机默认开启，分别尝试最近成功网络和最近配对设备；用户手动操作优先，断开蓝牙后不自动重连，运动感应仍默认关闭。BLE支持向电脑输入和单个外接键盘/手柄的两种角色，同一时间只连接一个设备。蓝牙音乐使用HID媒体控制，不是A2DP音频播放。

局域网 App 最多接入 4 台；上游 Wi-Fi 可用时采用 APSTA 和 IPv4 NAPT 自动共享，无上游时提供本地组网。普通关闭热点保留原 STA，退出 App 或深睡关闭热点；热点内提供SD文件管理和设备图形密码验证的只读密码网页。详见[局域网](lan_hotspot_20260920.md)。密码本通过Wi-Fi同步，独立vault分区双槽保存；编译同步鉴权密钥与原存储身份/数字PIN分离，HTTP请求和bundle响应必须匹配证明。仅轮换双端同步密钥不影响已有密码读取；每次有效同步全量覆盖，不限制版本。SHA-256改用每次独立上下文的软件实现、4KiB协作分段；PIN的PSA HMAC路径保留。软件AES-GCM长数据每2048字节协作让出CPU，认证失败清输出，存储/PIN格式不变。详见[同步说明](vault_sync_20260920.md)。

普通PWR控制亮灭屏；文本阅读/加载及相册图片查看页（含图片加载/失败）单击返回文件列表，返回列表/退出即释放接管，屏幕已灭时优先唤醒，长按不变；设置和快捷面板中的深睡以RTC计时和低待机为主，快速双击PWR后重新启动。各App按关屏/退出规则停止或暂停活动，详见[贡献说明](../../CONTRIBUTING.md)。

自动省电、插电保护和供电确认由`power_policy`/`power_runtime`/`supply_policy`管理，GUI决策与worker最终许可复核分开；暗屏后台活动不延期，自动休眠、阶段时间、供电及连接保护开关优先，保护解除重新等待。未知供电在启动时暂按插电保护，连续30秒未检测到外电信号后按电池运行执行省电；仍可手动启用供电保护。动态频率240～40MHz及自动Light-sleep受忙任务/性能锁约束，保持RC_FAST PWM和LVGL单调时间；NVS power_v2兼容旧配置。用户入口与硬件限制见[电源管理](power_management.md)。

9月30日将轻量CHG/缓存USB供电轮询与慢worker分开：`Battery::pollSupply`使用独立短锁与1秒限频，SystemService和自动策略都可调用；ADC仍在worker以亮屏5秒/暗屏15秒采样。触摸IRQ只请求数据，有效按下/移动/松开才计活动，读取失败和暗屏触摸不刷新空闲；GUI决策前预读缓存，亮屏轻睡启用触摸GPIO唤醒、暗屏关闭该来源。默认插电保护与手动确认不变，未据此宣称实测续航。

网络校时由SystemService统一管理，零等待轮询实际SNTP完成信号；三服务器各20秒，重复请求合并，超时/断网/深睡释放客户端。手动设置时钟在同一worker先停止SNTP再应用，防止旧请求覆盖；设置页按状态修订号更新，无回调持有App/LVGL指针。退出设置后的有界校时仍可收尾，排队/进行中限制亮屏省电关无线，但不延长暗屏深睡期限；自动校时只亮屏发起。详见[网络校时](network_time.md)。

SD通过 `sd::Session` 管理句柄、访问代次和错误恢复；设置提供安全弹出，先阻止新I/O、完成保存/关闭，待卡就绪后卸载并关闭总线信号。显示可插拔后仅用户读取/刷新才能重新挂载，旧任务不能恢复访问；卡槽3.3V供电仍存在，没有软件降压/断电能力。

相册JPEG/PNG由单个按需worker读取和解码，GUI只接收Job结果；采用视口解码与SD分块缓存，缩放/平移按预算加载，退出协作取消。图片worker纳入storageIdle，参与深睡/弹出等待。JPEG保留基线快速路径，渐进式走有源系数/扫描次数/协作超时预算的photo_jpeg，PNG逐行处理，缓冲分配有上限；图片查看为240×240全屏。

FC共享C/C++ NES头解析器，登记35种Mapper和基础NES2，含VRC6音频及MMC3变种；摇杆外圈66px、圆钮44px，中心(33,33)贴左上，保留120×120触区。FC在系统运动许可开启后临时获取IMU重力方向，固定缓存供GUI读取，暂停/退出释放，不改变系统运动偏好。三个手动槽在暂停帧边界保存/读取；独立自动槽每累计一分钟游戏时间捕获快照，由按次写盘任务完成，正常退出等待收尾。GUI只发请求，退出释放SD会话/缓冲。参见[兼容范围](photo_fc_compatibility.md)、[控制](fc_touch_controls.md)及[存档](fc_saves.md)。

新增GIF使用单worker流式解码、双帧缓冲和持续呈现时间线；播放不缩放，退出释放解码器、SD会话及帧。编程速查/设计模式按需加载资料，文件管理使用受控SD修改任务，摩斯音频退出停止。详见[新增应用](learning_files_morse.md)和[GIF](reader_photo_random_20260921.md)。

8Bit音乐用受限JSON乐谱实时合成22050Hz PCM，目录/播放任务分别按需6KiB PSRAM栈，单曲加载后关闭SD文件，256样本一块输出；暂停/停止关闭流，退出释放乐谱和任务。与录音/FC/游戏音频互斥，亮屏播放受忙保护，暗屏后仍按显式设置和期限收尾休眠。见[8Bit音乐](chiptune.md)。

录音删除以固定path/卡代次/size/mtime作为身份，在worker取得修改权限后再次核验；确认键置左，避免与右侧垃圾桶同位连点。目录刷新失败保留旧列表且禁用；新文件只在目标ENOENT时创建，目标存在拒绝覆盖，保存改名失败保留.part。元数据检查不代替内容hash或备份，实卡丢失原因不能全部归为已复现的误触。见[录音说明](recorder_ui_dsp_20260919.md)。

## 时钟自学习与测速

`core/clock_discipline.*` 通过两个链接包装在 SDK 最终深睡校准处执行三次长测量，并在 SNTP 修改时间之前捕获偏移。SNTP 停止的同步边界之后，SystemService worker 将可信结果交给 `clock_drift_model.hpp`；Settings 保存带校验的 `rtc_drift_v1` 模型，RTC 保留区保存观察窗口、ticks 和校准信息。`main.cpp` 在 Settings 加载后、UI 之前应用一次唤醒补偿。学习不会创建定时唤醒，细节见[时钟自学习](network_time.md)。

`apps/speed_test.*` 只管理界面、曲线和请求；`core/speed_test.*` 的按需 worker 执行 HTTPS、独立 ICMP 与有界调度，`speed_test_model.hpp` 定义统计口径，`speed_test_store.*` 保存 SD JSON。界面通过快照接收结果，网络任务不持有 LVGL 指针。历史读取/删除也在 worker 执行，SD 代次与修改权限保护目标，退出协作取消；系统休眠等待网络、探测与保存收尾。详见[网速测速](speed_test.md)。

## USB电脑投放

`DisplayCast`在LVGL刷新事件中捕获RGB565画面，GUI只进行有界复制/非阻塞邮箱发布；core0任务负责编码和USB通信，PC端呈现后ACK。只有手动开启才创建三个帧缓冲和任务，关闭时成对卸载驱动并清零释放；主UART诊断保留，辅助USB日志仅投放期间抑制。

首帧ACK后关闭背光但保持逻辑亮屏及LCD刷新，避免暂停游戏/输入/IMU。投放是系统级手动会话，离开设置仍继续；普通关屏/深睡取消，退出接收器或连接超时恢复背光，深睡等USB清理。详见[投放说明](usb_display.md)。用户确认电脑方式可用；CM818-45363拓展坞直连显示器方案已放弃。

## 主题、历法、小游戏与截图

五套主题保存稳定编号，默认10；设置确认后通过系统服务安全重启应用主题。HTML的15套候选只作预览。四种时钟中黄历使用离线公农历/节气表，中央时辰与八字动态显示，仅变化单字滚动替换；万年历与小游戏按需建立UI，退出释放定时器/订阅。详见[功能说明](themes_calendar_games.md)。

小游戏物理与显示分离：小恐龙障碍/道具间距由模型约束，场景为固定对象池；迷宫15关，每3关升级，分5×5至9×9五档，运行中更新小球位置/材质纹理和音效参数，临时IMU需求在暂停/退出撤销。游戏内菜单覆盖场景，阻止菜单事件穿透。共享game_widgets的紧凑字库回退数字/图标字体，避免动态分数/箭头缺字。

KEY双击启动一次截图，GUI有界复制完整RGB565帧，短时worker编码PNG到SD screenshots，Session保护写盘和关闭。成功后改名、清零释放帧，深睡/主题重启等完成；FC游戏按键接管区与图片页禁用，PWR不变。详见[截图说明](screenshot.md)。

## 小屏界面和构建

屏幕240×240，布局紧凑且保持可触控面积。Wi-Fi、热点和密码本地址输入框高度统一36px，共用系统文本输入器；密码本数字PIN使用独立全屏键盘。文本、相册、随机前台接管BOOT/KEY单击，退出恢复音量行为。

工程从新目录执行`Build.cmd`，使用已激活的外部SDK和Ninja -j2；构建目录由本工程生成。当前生产源码按已烧录来源同步；保留独立初始化、分区布局和固定依赖。旧阶段日志、备份恢复指令和被移除功能的设计说明不作为当前依据。

触控、无线互联、音质、FC流畅度和长期功耗仍需实机验收，编译和静态检查不替代运行测量。

## 新增系统能力及精简

- `usb_storage.*`提供TinyUSB MSC同步扇区读写，512字节内部中转缓冲、互斥I/O和显式SD所有权交接；本地强回调避免引入厂商异步VFS自动挂载路径。开机开发与烧录，用户确认可强制切回；错误不假装SD已安全恢复。详见[读卡器](usb_storage.md)。
- `ui/quick_panel.*`在现有触摸读取和GUI泵接入手势，不新增I2C轮询；屏幕顶边下拉、从底部把手上滑关闭，控件按需创建，当前App声明是否允许。状态来自系统快照，命令异步执行；面板独占触摸/键盘焦点与分页输入，恢复时清旧事件。详见[快捷设置](quick_settings.md)。
- `recorder_playback.hpp`将播放与双麦录音处理分开：普通/快退共用2KiB，快退倒序/FIR抽取；快进按需Sonic保调2倍。`game_audio.*`/`game_synth.hpp`以小PCM块实时合成两个游戏的音乐/音效，无SD样本依赖。
- `vault_storage.cpp::FlashIo`每次读写只分配1KiB内部缓冲，取消可中止，结束清零释放；I/O失败与算法校验失败分开，不选择旧槽继续覆盖。
- 系统输入控件隐藏即释放；无调用者的触控观察包装、独立深睡App、语音助手及自有模型/训练代码已移除。主题初始化核验GUI锁，应用背景不透明、导航时整屏重绘，正文独立15px字体/20px行高实现12行。
- 当前分区无OTA应用槽或更新入口；保留factory、NVS、assets及vault布局。未分配区域不等于可直接多烧录的程序容量。

具体编译/交付证据集中在[当前状态](../current-state.md)，文档整理不触发构建或设备访问。

## 2026-09-30稳定性整理

关机和热点关闭补齐存储/媒体、驱动状态和失败收尾，SD修改使用独占会话；文件管理目录全局排序后按游标分页。文本与相册采用共享八行控件池，38px行高保留原主题间距、滚动位置及回收行按压校验，目录数据仍最多256项。

录音暂停、游戏/摩斯静音及FC暂停改为通知等待，仍有有界电源复核。活跃播放和游戏帧时序保持；退出同步撤销任务句柄，FC读档预览仍允许有限重试。通知仅唤醒检查状态，不能取代状态机或强杀任务。

时钟每分钟持久化保留，网络/手动校时后重排下一分钟，沿用NVS合并与失败重试，关机/深睡仍强制保存。蓝牙只读兼容接口保留，连接行为不变。

共享GPIO ISR通过项目链接包装只安装一次，保持原非IRAM策略，真实错误仍返回且允许重试。旧LVGL接口、断言include及宏/类型/RTC section警告已处理；FC热函数独立属性不覆盖SDK。上述为该历史阶段的处理记录。当前编译/启动范围见[当前状态](../current-state.md)；本次时钟适配仍有 SDK 唤醒原因 API 弃用提示，不宣称当前构建零警告。

旧Brookesia组件不参与构建。固定依赖通过准备脚本重新获取，必须保留清单及适配补丁。最新源码/链接/启动证据及实机待验收项见[当前状态](../current-state.md)。

统一显示方向、触控映射及重力App锁定见[方向架构](screen_orientation.md)；热点HTTP服务见[局域网](lan_hotspot_20260920.md)，图片worker/SD分块缓存见[图片处理](photo_rendering.md)。

MP3的`mp3_player`将SD解码与音频输出分任务，GUI通过状态快照显示歌词；退出停止并释放。FC画面由`fc_video.hpp`生成240×240的1:1裁切输出；C/H模式输入由统一蓝牙输入路由分发，参见[MP3](mp3_music.md)和[FC显示](fc_rendering.md)。

小智AI的会话、音频与网络由独立worker协调，GUI读取状态；工作栈及音频资源随会话释放，参见[小智AI](xiaozhi_ai.md)。
