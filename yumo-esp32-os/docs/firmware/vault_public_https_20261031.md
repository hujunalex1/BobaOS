# 密码本公网HTTPS地址与同步

更新日期：2026-10-31。本功能已在开发工程完成编译和回归，当前设备是否包含本功能以[当前状态](../current-state.md)中的烧录收据为准；同步源码到final不表示设备已更新。

## 地址怎么填

在设备「密码本 → 连接」中保存密码服务的入口地址，再点击同步。设备必须已连接能够访问该服务的Wi-Fi；蓝牙不是同步前提。

| 示例 | 含义 |
| --- | --- |
| `https://vault.example.com/` | 公网HTTPS域名，默认443端口；末尾根路径斜杠可省略 |
| `https://vault.example.com:8443` | HTTPS域名与明确指定的外部端口 |
| `http://192.168.1.20:9080` | 原有局域网HTTP地址，继续兼容 |

地址需包含 `http://` 或 `https://`；HTTP默认80，HTTPS默认443。支持ASCII域名和规范IPv4，端口1～65535。自动去掉首尾空白、规范化大小写及端口数字、去掉根路径末尾的一个斜杠。

只填写服务入口，不附加 `/api/device/bundle`、其他子路径、查询参数、片段或用户名密码；这些输入会明确拒绝，避免误连到不同服务。当前不接受IPv6字面量、裸域名或中文域名文字；国际化域名应使用服务证书对应的ASCII形式。

SD回退配置位于 `/config/vault.json`，仍只包含版本与地址：

```json
{"schema":1,"url":"https://vault.example.com/"}
```

本地保存、加密配置读取和SD导入共用同一地址规则。本地地址失败后可以从SD尝试一次，仅SD地址同步成功才将其保存；不保存失败地址，也不无限后台重试。

## 公网转发与证书

服务公网域名转发到原密码服务即可，无需为设备另开端口，也无需把公网IP固化到固件。设备使用外部可访问的协议与端口；内层容器监听端口可以不同。入口必须把现有 `/api/device/*` 路由转发到同一服务，并保留鉴权请求头和响应头。

HTTPS启用ESP-IDF根证书集合验证服务端证书及域名。已有显式CA配置优先；没有显式CA时使用证书集合，不关闭证书校验、不降级HTTP。设备时间尚未校准时先提示联网校时；证书日期错误也会提示检查时间。

设备直接请求最终地址，不自动跟随重定向携带鉴权信息；若入口把HTTP跳到HTTPS，应保存最终HTTPS地址。服务的网页来源检查、浏览器入口地址配置与设备GET同步鉴权是不同路径；设备地址只用于密码同步。

## 同步规则与失败提示

已有Bearer身份、同步证明、响应头校验、256KiB加密包上限及认证解密流程保持。成功同步仍以服务端完整列表覆盖本地，包括删除及有效空列表；网络、鉴权、文件或解密失败保留原库，不重置图形密码、身份、NVS或SD。详见[同步协议与全量覆盖](vault_sync_20260920.md)。

| 提示类型 | 处理 |
| --- | --- |
| 设备时间未校准 / 证书日期无效 | 先连接网络校时，核对当前日期 |
| 域名解析失败 | 检查设备Wi-Fi、DNS及域名解析 |
| 证书与域名不匹配 / 不受信任 | 检查入口证书域名和完整证书链 |
| 地址发生跳转 | 保存重定向后的最终HTTPS入口 |
| 502 / 503 / 504 | 检查公网转发及内层服务是否可达 |
| 401 / 403 / 服务端密钥校验失败 | 核对对应部署身份与双端同步密钥；不要清库处理 |

单次SDK网络操作超时由3秒调整为10秒；传输流程在各阶段和读取返回后检查30秒期限、取消、关屏与待休眠状态。这不是强行打断阻塞SDK调用的硬性30秒上限。读取结束时再次检查取消，避免关屏或取消恰好发生在EOF时仍提交同步成功。

诊断日志只记录TLS、证书及套接字错误码，不输出同步密钥、证明、Bearer令牌或密码内容。

## 维护入口

- `firmware/main/core/vault_origin.hpp`：共享地址解析和规范化。
- `firmware/main/core/vault_connection.cpp`、`vault_json.cpp`、`password_vault.cpp`：SD、本地加密配置与保存入口。
- `firmware/main/core/vault_sync.cpp`：HTTPS证书、请求鉴权、响应和取消收尾。
- `firmware/main/apps/password_vault.cpp`：连接页地址输入及说明。
- `tooling/firmware/test_vault_origin_runtime.py`、`test_vault_https_runtime.py`：生产代码宿主回放，均使用合成身份与数据。
