# 编程速查、设计模式、文件管理与摩斯电码

这四个应用已纳入当前24个应用的菜单，设置保持最后；图标各不相同。所有App按需创建，退出销毁界面和实例；文件保存/音频停止采用协作收尾，不保留后台App。

## 编程速查

将工程内 `resources/sdcard/programming/library.ykb` 复制到SD卡 `/programming/library.ykb`。找不到文件时可通过文件管理检查路径，插回卡后手动刷新/重读。固件本身不会替用户复制该知识包。

当前源码知识包449条（版本20261030），保留原419条；“工具”新增Kubernetes 18条与K9s 12条。内容包括Java基础与23种GoF设计模式、MySQL查询等基础操作、Linux/Maven/CMD/PowerShell及Kubernetes/K9s操作命令。资料可阅读，设备不执行其中的Java或命令行代码。新增知识包已生成并通过内容检查，但当前没有将其写入用户SD卡的成功收据；仅烧录固件不会增加设备SD里的条目。

- 首页保留分类入口；进入分类/知识点列表后选项带序号，纵向滚动，不左右分页。
- 知识点顶栏标题只占一行，超出隐藏。描述用小标题区分各部分，在一页中上下滚动。
- 有“示例片段”时以一个按钮切换代码/描述；没有示例时不显示切换按钮。
- 代码保留行结构，超长行可左右拖动；这不等于左右切换知识点。
- 五角星用于收藏，支持搜索、最近阅读和阅读位置记录。记录由设备写入`/programming/state.bin`。

更新知识包时保留用户的`state.bin`，不要用空记录替换。知识索引与当前内容按需加载，退出释放引用和界面，末次阅读/收藏写入安全结束后释放任务；无后台全库预加载。

## 设计模式

26课覆盖23种GoF设计模式及补充对照内容，共78个活动。进入后选择课程，先看本关目标，再按引导逐步操作场景中的角色/连接，运行模拟、观察结果、修正并继续；可查看概念边界与Java代码。主流程是交互模拟，不是连续二选一问答。

代码支持保留原行并横向查看；模拟只说明对应概念，不在ESP32上执行Java。课程中的角色关系、行为流程和技术定义已进行过源码/内容校对，后续新增关卡应继续检查这种对应关系，不把动画表现当作技术定义。

课程包位置为`/patterns/lessons.ypg`，学习进度为`/patterns/progress.dat`；工程示例在sdcard/patterns（历史回放记录）。课程随固件内置：SD中缺包时可补入，已有不匹配文件不覆盖，使用内置课程回退；没有可用SD仍可学习，但不能据此承诺进度已落盘。

不要删除用户`progress.dat`，也不要把有效冗余记录当缓存清理。退出停止场景更新、释放课程/UI/历史状态，必要进度保存协作完成；模拟运行期间不展开快捷面板。

## 文件管理

从SD根目录进入，支持浏览子目录、创建文件夹、重命名、确认删除、复制及移动。复制/移动先选源，再到目标目录粘贴。名称输入使用系统输入控件，删除需确认。

操作在按需任务中执行，目录分页展示，访问代次及SD独占机制防止与前一App尚未完成的读写交错。退出协作取消并关闭句柄，不能强杀持锁任务。文件操作忙时不开放下拉面板。

安全弹出仍从“设置→系统与电源”执行；USB读卡器占用SD时，本机文件操作不可用。该App管理真实SD文件，历史合成文件测试并不代表已在用户SD执行破坏性操作。

## 摩斯电码

固定黑绿界面，四种模式：

| 模式 | 操作 |
| --- | --- |
| 模拟输入 | 按住底部输入键，按时长判定点/划，带声音；停顿后实时转换。 |
| 手动转换 | 使用点、划、空格构成电码，再点击转换；不能转换的部分标红。 |
| 字典 | 按字母、数字、符号分区纵向浏览；先选符号，再次点击播放对应电码。 |
| 练习 | 选择内容与顺序/随机，按长短输入；正确显示颜色反馈，错误旁显示正确提示，可重复练习，左右按钮切上一/下一项。 |

退出取消输入状态、定时器和音频会话；不保留后台练习。快捷面板仅在字典或尚未开始的练习页面可用，避免与长按输入冲突。首页空按钮占位问题已随前序修复纳入当前版本。
