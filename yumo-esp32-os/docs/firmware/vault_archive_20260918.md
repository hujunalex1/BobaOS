# 密码本加密导入导出

本页路径以工程根目录下的 `firmware/` 为起点。本文说明现有行为；构建、设备和服务状态以[项目当前状态](../current-state.md)为准。

## 全部密码加密导出

登录后点击列表下方“全部加密导出”。浏览器下载 `.jyvault` 文件，包含工作、应用、网页、其他四类的全部密码，不受当前分类、搜索结果或选中条目影响。保留名称、账号、密码、用途/URL、备注、收藏和条目标识。

导出的是现有JYVAULT2加密快照，沿用部署密钥；不改变库内容或同步版本。无需另设文件密码。不包含管理员密码、管理员散列、设备PIN或明文部署密钥。

恢复必须使用同一套 `server/deployment/local-keys.json`。管理员密码不是文件解密密码；换管理员密码不影响旧文件的导入。迁移到NAS请保留配套部署目录，不要重新生成密钥。文件本身不提供丢失密钥后的恢复能力。密钥嵌入固件的既有单人局域网边界不变。

## 解密、去重导入

1. 登录，点击“加密文件导入”，选择 `.jyvault` 文件。
2. 点击“解密并预览”。解密只在服务端内存进行，普通模式浏览器只接收分类及元数据，超管模式预览可接收并展示密码。
3. 检查新增、合并更新、无变化和最终总数，点击“确认去重导入”。
4. 完成后在设备密码本点击“同步”，设备固件无需更新。

去重键为“分类＋账号＋密码”，账号密码严格比较，保留大小写和首尾空格；同账号不同密码、相同账号密码但不同分类分别保留。文件中的重复项及其与现有库的重复项都会合并，不对历史库做无关的全库清理。

- 新条目保留原名称等字段，不使用CSV的“名称取账号”规则。
- 匹配已有条目时保留原ID、名称和非空用途；用途为空则补齐。额外名称以“名称：…”、不同用途以“用途：…”补入备注，与导入备注去重后以英文逗号拼接。收藏只要任一为真就保留。
- 相同ID但不同账号密码的记录不覆盖已有条目，为新增记录生成新ID。
- 没有删除、覆盖全部库或回退版本行为。空文件为无操作；重复导入无变化时不写库、不增加同步版本。文件中的旧版本号不会覆盖服务端当前版本。
- 有变化时一次事务保存，只增加一次同步版本。预览后若库被修改，确认返回冲突，需重新预览。
- 管理员密码、设备PIN、部署密钥都不被导入文件更改。

限制：文件最大256 KiB、最多256条源记录、去重合并后全库最多256条。沿用现有设备字段限制：名称96字节、用途192字节、备注256字节、账号密码可打印ASCII各128字符。合并备注超过256个UTF-8字节时按字符边界截去尾部，其他字段不截断。损坏、篡改、密钥不匹配、格式非法或容量超限时整批拒绝，不静默跳过条目。发生网络异常时，先刷新列表确认是否已提交，再重新预览。

取消、更换文件、锁定和切到后台会清理浏览器文件/预览暂存，迟到响应不会重开界面。已经送达服务端的确认请求不会因浏览器切后台而撤销，应以刷新后的列表为准。原始上传文件和解密中间文件不落盘；只有确认成功的加密快照持久化到SQLite。没有增加自动备份或常驻导入任务。

## CSV只用于网页

“导入 CSV”只出现在“网页”分类的列表中。无需再选分类，后端也会拒绝工作、应用、其他分类的CSV请求。CSV依旧按账号密码去重、名称取账号名、首条完整URL保留、后续域名最多保留10字符、去重补入备注，单条备注256字节截断；跳过无账号或不支持字符行并报告，按账号排序。其他分类的迁移使用加密文件导入。详见[CSV说明](vault_csv_import_20260918.md)。
