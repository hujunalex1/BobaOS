# USB连接模式与SD卡读卡器

入口：“设置→系统与电源→USB连接模式”，或下拉快捷面板的USB按钮。每次开机均为“开发与烧录”，不会记住上次读卡器模式。当前版本与验证范围见[当前状态](../current-state.md)。

## 两种模式

| 模式 | 用途和限制 |
| --- | --- |
| 开发与烧录 | USB Serial/JTAG用于烧录、日志和手动画面投放；SD由设备使用 |
| SD卡读卡器 | 电脑将SD识别为可读写磁盘；电脑独占整张SD，本机的文本、相册、录音、FC及SD同步配置暂不可访问 |

读卡器与[电脑画面投放](usb_display.md)互斥，先停止投放再切换；切回后按当前枚举重新选择串口，不绑定固定串口。此功能不提供DP/HDMI输出。

## 使用流程

1. 插好SD卡，用数据线连接电脑。退出使用SD的应用，等待录音、存档、截图等保存结束。
2. 在设备选择“SD卡读卡器”。设备结束本地SD会话、卸载文件系统，再交给USB磁盘；等提示电脑独占后操作电脑文件。
3. 使用结束，先停止电脑复制、编辑及其他写盘操作；可先在电脑弹出磁盘，但这不是切回的必要条件。
4. 在设备选择“开发与烧录”，阅读提醒并确认。设备停止接受新命令，等待已经收到的读写和卡内部写入完成，然后主动断开USB磁盘、恢复开发接口。
5. 正常完成后重新挂载SD供设备使用；出现卡错误会保留隔离/弹出状态并提示，需检查后手动重试。USB或底层卸载失败时按提示重启，不能把失败状态当恢复成功。

设备无法替电脑提交还没有发到USB的写缓存；强制切回、拔线或断电可能丢失未完成的电脑写入。因此确认前必须停止复制，不把“设备确认切回”描述为任意时刻都绝对无损。

读卡器是系统会话，离开设置仍继续；亮屏时阻止自动熄屏及常亮低负载，手动深睡/主题重启仍需先结束读卡器。手动PWR关屏后，自动休眠按[电源设置](power_management.md)执行：默认插电不休眠；若用户允许且期限到达，设备先停止接收USB请求、完成已接收写入，再进入深睡。后台USB活动不会延长熄屏期限；请先在电脑结束复制并弹出磁盘，设备无法提交电脑未发出的缓存。

如需物理拔卡，应先切回开发模式，再走[安全弹出SD卡](sd_media_fc_20260918.md)流程。卡槽仍为3.3V供电，软件不支持降压/断电。

## 实现与验证边界

`main/core/usb_storage.*`、`usb_storage_io.hpp`和`sd_media.*`实现显式所有权交接，TinyUSB MSC同步读写512字节扇区，内部小缓冲处理未对齐访问，互斥保护进行中的I/O；失败返回真实SCSI错误。没有同时让设备FAT和电脑写同一张卡，也不链接厂商自动VFS挂载/延迟写入路径。

已通过对应源码/宿主检查、编译和启动核验；尚未记录本版在电脑上的大文件复制校验、异常拔线或长期传输实测。编译/启动通过不代表主机写缓存及所有SD卡均已验收。
