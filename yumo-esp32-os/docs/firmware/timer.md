# 计时器（秒表）

更新日期：2026-10-19。对应 2026-10-16 成功烧录基线，来源及验证范围见[当前状态](../current-state.md)。应用名称为“计时器”，当前提供正向秒表和分段记录，不含倒计时闹铃。

## 操作与布局

顶部三个触控按钮从左到右为返回、暂停/复位、开始/继续/记录；运行状态通过按钮文字提示。中间为大号秒表，按位数自动适配画框；下方显示当前分段及已保存的分段，不显示“记录、分段、累计”表头。

| 操作 | 未开始或暂停 | 正在计时 |
| --- | --- | --- |
| KEY 单击 / 右上触控 | 开始或继续 | 记录当前分段 |
| PWR 单击 / 中上触控 | 复位全部计时与分段 | 暂停 |
| 左上返回 / BOOT 双击 | 退出应用 | 退出应用 |

计时器内接管 KEY/PWR；KEY 双击不截图。BOOT 双击退出，不能改成 KEY 双击退出。长按 PWR 保留系统关机行为。

## 分段与计时

首条是始终固定可见的动态分段，序号、分段和累计均为白色。计时过程中两种时间持续变化；记录后当前信息进入下方历史，新分段从零开始，累计继续。暂停时冻结，继续时接续。历史最新在前，最多保留最近99条；最短分段标绿、最长标红，全部相等时使用普通颜色。历史可以滚动，动态首条不随历史滚走。

使用单调微秒时钟计算，界面显示到百分之一秒；联网校时不会改变已计时长。显示分辨率不等于实测绝对计时精度。记录仅保存在本次应用内存中，退出后清空，不写 SD。

## 电源与生命周期

前台应用通过 StayLit/KeepSession 提示保持亮屏和会话，不修改用户全局熄屏偏好。退出释放按键接管、停止并删除界面定时器，恢复系统原有省电设置；顶部快捷面板在应用内禁用。

实现入口：`firmware/main/apps/timer.cpp`、`core/stopwatch_model.hpp`、`core/timer_key_state.hpp`、`core/button_mgr.cpp`。宿主回放 `tooling/firmware/test_timer_ui.py` 使用生产模型、按键回调和 LVGL；板级及系统副作用采用桩。宿主通过不等于真实按键延迟、整机功耗已验收。
