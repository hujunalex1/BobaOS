# 页面隔离、LCD残像缓解与空闲性能

更新日期：2026-10-31。本文所述图形页面、性能和屏幕保护代码已随2026-10-30固件烧录；设备版本与验证收据见[当前状态](../current-state.md)。

## 页面背景与残像的区别

各应用使用独立页面，图形密码输入板显式绘制完全不透明背景，半透明外圈与连线只与当前页面背景混合。

用户反馈的剩余现象是整个桌面的极淡图像肉眼可见、内部截图不含残影，触发截图刷新后仍存在，等待后逐渐淡去。这支持临时LCD图像残留的判断，不能据此断言永久烧屏，也不能用软件截图或宿主像素比较证明面板光学效果。

当前板级ST7789初始化已与厂商对应实现核对；没有尝试修改VCOM、电压、gamma或反相寄存器。软件措施侧重减少固定高对比度图像长时间驻留。

## 自动保护行为

- 仅桌面和密码本闲置图形输入页参与；无真实输入120秒后显示不透明深灰背景及低对比度 `HH:MM` 时钟。
- 每秒检查时钟文字是否变化，每15秒在8个位置间移动；内容未变不额外绘制。
- 首笔触摸只恢复页面，按下、拖动和松开均被消费；下一笔触摸才操作页面。实体按键及蓝牙键盘仍执行原功能，同时恢复页面。
- 自动熄屏先执行；若用户设置早于120秒熄屏，保护页不会延长亮屏。页面切换、灭屏及休眠移除保护层。
- 绘制图形、校验密码或异步任务进行中不遮挡；快捷面板、文本输入、配对提示、系统信息、截图和投屏期间不进入。
- 时钟APP、秒表、游戏、阅读和相册等其他应用不启用该保护页。亮度、休眠偏好、校时、无线和持久化设置不变。

保护复用GUI轮询，不增加后台任务、定时器或帧缓冲；进入创建两个LVGL对象，退出释放。目的在于减少后续残像累积，不承诺清除已有残像。

## 同版性能与逻辑修正

| 部位 | 当前处理 |
| --- | --- |
| 状态栏、快捷面板、秒表 | 文字或样式发生变化才更新，避免空闲时重复重绘 |
| 随机PK | 游标实际推进后才绘制，保留双方原计时及结算 |
| Wi-Fi状态发布 | 按扫描版本更新AP列表；内存不足保留完整旧快照，下次重试 |
| GIF与媒体任务 | 同一错误只提示一次；任务创建失败明确显示内存不足，退出先解绑显示帧再释放 |
| BOOT/KEY延迟单击 | 按下时记录页面会话，过期点击不进入新页面；双击与应用接管优先级保持 |
| 休眠取消 | 最终取消检查和终态提交共用显示互斥锁，外设关闭仍在锁外 |

这些修正不改变应用功能、存储身份、分区、BLE策略或电源设置优先级。没有通过调整任务优先级或删除已有功能来掩盖卡顿。

## 验证及实机边界

保护层的生产LVGL回放通过57,516项断言：8个位置不越界、底层高对比图像被完全遮盖、700次无变化轮询零额外flush、首笔触摸不下穿、100次进入退出内存增长0字节。窗口、输入和显示对象清理均有验证；缓存Windows LVGL端口的全局关闭曾超时，该宿主关闭路径不作为设备页面退出结论。

性能回放中2,993次内容不变轮询的额外条带提交从23,398降为0，前后画面及游戏状态摘要一致；Wi-Fi空闲发布、低内存恢复、媒体故障、按键会话和休眠竞争均有针对性回放。次数是检查量，不是独立功能数，也不是ESP32帧率或功耗实测。

上述版本已完成791项源码检查、45个目标编译器模型、3项防护和四区烧录/单次启动校验，45项既有排除保持。残像光学改善、触控延迟、整机功耗和长期运行仍需设备观察；短时启动不等于这些项目全部验收。

维护入口为 `firmware/main/ui/screen_protection.*`、`screen_protection_model.hpp`、`window_mgr.*`，以及 `core/button_mgr.cpp`、`power_mgr.cpp`、`connectivity.cpp` 和对应媒体应用。针对性回放工具在 `tooling/firmware/`，构建与检查方式见[构建说明](../build.md)。
