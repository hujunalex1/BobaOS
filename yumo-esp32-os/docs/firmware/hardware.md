# 硬件与板级边界

目标为ESP32-S3-Touch-LCD-1.54；板级组件位于 `firmware/components/esp32_s3_touch_lcd_1_54`。

| 部件 | 当前映射与能力 |
| --- | --- |
| 显示与触摸 | 240×240、SPI RGB565，CST816S触控，LEDC背光调光 |
| 实体按键 | BOOT=GPIO0，KEY=GPIO4，PWR=GPIO5；空闲高电平 |
| 电池开关 | GPIO2控制BAT_EN，拉低用于电池供电下关机 |
| 电量采样 | ADC1通道0/GPIO1，3:1分压，电压估算电量；没有库仑计 |
| 充电状态 | GPIO3低表示正在充电；高不能区分充满、拔线或无电池 |
| 音频 | ES8311播放、ES7210双麦采集 |
| 运动 | QMI8658六轴IMU，I2C GPIO41/42；没有磁力计，不能提供绝对罗盘方位 |
| SD | 卡槽VDD/外部上拉直连3.3V，无软件断电开关，未接入可用插卡检测 |
| RTC | 内部 RC_FAST/256；标准板无独立 RTC 芯片或 32.768kHz 晶体，完全断电需重新校时 |
| USB | Serial/JTAG开发、软件SD读卡器及电脑画面接收；没有DP Alt Mode/HDMI输出 |

普通PWR亮灭屏、深睡快速双击唤醒，以及App对按键的临时接管均由系统管理。详见[电源](power_management.md)、[FC控制](fc_touch_controls.md)、[阅读/相册](reader_photo_random_20260921.md)、[截图](screenshot.md)。

本板没有独立VBUS检测脚。连续30秒没有USB在线/充电信号后，软件按用户选择推定电池运行；这不是硬件确认已拔线。满电普通充电器可能无法识别，可手动恢复插电保护；不根据电量百分比猜测VBUS。

安全弹出SD只结束读写、卸载并停止MCU总线驱动，不降压、不关闭卡槽供电；插回需要读取或刷新。不能承诺带电拔插绝无电气风险。

USB投屏时是否关闭本机背光由设置中的独立开关控制，默认关闭；不会把只关背光当成逻辑熄屏。投屏、USB读卡器互斥，不支持扩展坞直连HDMI。硬件能力不等于长期功耗、掉电或所有外设兼容性已验收。

## USB 有线键盘边界

本板 Type-C 按受电设备设计：CC1/CC2 使用 5.1kΩ 下拉，VBUS 进入系统供电/充电路径，没有电池升压输出 USB 5V 的电路。电池供电时仅用 C-to-C 线连接普通取电键盘，不能为键盘提供工作电源。

USB 有线键盘试验已按用户要求撤回并独立归档，当前已烧录版本和源码交付不含该驱动或模式入口；不因外部供电就自动获得键盘支持。现有蓝牙键盘、USB 投屏和 SD 读卡器保留。未实施此前讨论的离线/在线 AI 应用。

## RTC 硬件核查（2026-10-14）

本次依据厂商标准板 [ESP32-S3-Touch-LCD-1.54 官方原理图](https://files.waveshare.com/wiki/ESP32-S3-Touch-LCD-1.54/ESP32-S3-LCD-1.54-Schematic.pdf) 核查：图中只有 ESP32 主时钟的 40MHz 晶体 X1，未见独立 RTC 芯片或 32.768kHz 晶体。结论适用于该标准板原理图；没有拆机确认每个硬件修订版。

组件清单保留 PCF85063A 依赖不代表实板装有该芯片，当前固件也没有调用其驱动。GPIO15/16 在本工程分别承担 SD CMD/CLK，不能直接视为可用的 32k 晶体引脚。

设备深睡依靠 ESP32 内部 RTC 域和 RC_FAST/256，保持供电时可计时；完全断电后不能恢复断电时长。当前采用实际入睡前加长校准、联网学习频偏、离线唤醒补偿，详见[时钟自学习](network_time.md)。若增加独立晶体 RTC，需要另行硬件接线/供电与驱动开发，不是打开现有库即可获得。
