# 密码本使用与维护

更新日期：2026-10-31。当前源码与设备最近烧录版本分别见[当前状态](../current-state.md)。现用服务中心网页、设备密码本及设备热点网页是不同入口；设备管理图形密码与服务网页管理员密码相互独立。

## 分类与新增

| 分类 | 分组与详情 |
| --- | --- |
| 工作 | 先选“单位 / 系统”，再选条目 |
| 应用 | 先选“应用名称 / 平台”，再选条目 |
| 网页 | 先选账号，再查看用途及密码 |
| 其他 | 直接列条目；不展示账号，“密码”改为“码值”，在已进入的功能页面中持续明文展示 |

设备、服务中心和热点密码网页采用一致分类语义。空分组显示“未填写”，按原字段精确分组，不合并密码。服务新建/编辑工作或应用时，可下拉选择已有单位/系统或应用/平台，也可手动输入新分类。详情与编辑使用相同属性名称。

服务网页登录、初始化和部署由独立服务项目维护。普通密码编辑留空保留原值，其他类使用“码值”且不显示旧账号；旧账号兼容字段不因普通编辑被清除。

名称、用途和备注支持中文；蓝牙输入的账号/密码/码值限制为最多128个可打印ASCII字符，不支持中文或换行，保留首尾空格。全库最多256条；名称96、用途192、备注256个UTF-8字节，备注超长按字符边界截断。

## 图形密码

设备管理验证统一使用全屏九点图形密码：至少连接4个不同点，跨过尚未经过的中点会自动补入。首次设置绘制两遍确认；从旧数字PIN升级时在设备本地重新设置图形，原加密条目和同步身份保留。**这是旧PIN格式到图形格式的一次迁移，已有图形密码不会在普通升级、编译或源码同步时重置。**

解锁、改密、超管及普通明文查看等管理验证都复用图形输入。中央半透明提示短暂显示后消失，绘制期间不重建控件。中心点15px、半透明外圈60px，外圈是视觉辅助，不改变点的命中规则；连线按变化区域刷新。

抬手后下一次GUI轮询提交，异步校验期间每20ms检查结果，空闲恢复100ms。PBKDF2仍为10000轮，复用同次调用的HMAC状态减少重复工作，保留失败等待、恒定时间比较、取消与让出CPU。宿主回放通过不等于实际ESP32验证耗时已量化。

图形页有不透明背景，应用使用独立页面。桌面与闲置图形页120秒无真实输入可进入低对比度移动时钟保护页，首笔触摸仅恢复；自动熄屏优先，绘制/校验/异步任务中不遮挡。这用于减少长期固定图像暴露，不承诺清除面板已经存在的残像。

## 设备界面与明文查看

拼贴主题将底部空余高度分配给上方三个功能按钮及两行分类按钮；列表按需复用控件。只有分类首页提供修改密码入口。

单条详情的顶栏直接显示名称，下方不重复名称。账号和密码直接作为对应蓝牙输入按钮的内容，点击直接发起输入；普通密码默认掩码，验证图形密码后可临时明文，再次切换可隐藏。简化后的操作提示放在详情底部，其余字段保留“用途：”“备注：”等属性标签。“其他”只显示码值及相关属性，不提供账号或隐藏开关。

超管验证图形密码后开启全局明文；关闭、关屏、退出或空闲锁定后清理授权。普通明文有时限和离页清理规则，其他类码值持续展示不代表绕过进入密码本的管理验证。

“二维码”将当前条目的明文文本详情实时编码，普通密码需先取得明文授权。二维码包含UTF-8文本及属性标签，不是外部链接，不保存二维码图片。二维码页30秒超时，返回/锁定时清理文本和像素。内容过长无法在小屏保持可扫码尺寸时明确提示，不截断密码。真实手机扫码效果仍需实测。

## 同步和蓝牙输入

同步需要Wi-Fi，不要求蓝牙；蓝牙用于向目标电脑或手机输入当前账号、密码/码值，回车单独发送，不自动追加。超管、单条展示与蓝牙私密输入继续遵守各自的授权和安全连接约束。

「连接」页支持HTTP/HTTPS的域名或IPv4，标准端口可省略，根路径末尾的斜杠可保留。公网使用最终HTTPS入口；设备保留证书和域名校验，时间未校准会提示联网校时。地址规则、反向代理和失败排查见[公网HTTPS同步](vault_public_https_20261031.md)。这一新增能力尚需后续烧录才会出现在当前设备上。

服务端完整有效列表覆盖设备，包括删除及空列表；传输失败保留原库。本地地址失败后可从SD `config/vault.json` 尝试一次，只有同步成功才保存新地址。密码文件位于独立vault分区，不放在SD；加密存储、同步身份和双方密钥保持原值。详见[同步协议](vault_sync_20260920.md)。

## 热点浏览器

打开局域网热点，手机连接该热点后访问设备显示的HTTP地址。密码入口绘制与设备密码本相同的图形密码，解锁后先显示工作、应用、网页、其他四个分类按钮，再进入上述分组查看明文并复制。该入口只读，不负责修改或向服务中心同步；初次图形设置在设备上完成。

浏览器会话限时，主动锁定、切回文件页、页面隐藏/离开等会清理明文；关闭热点、退出局域网或深睡停止服务。HTTP为明文传输，使用范围为设备热点。文件操作与访问地址见[局域网](lan_hotspot_20260920.md)。

## 改密、遗忘与迁移

设备改图形密码需原图形和两遍新图形。服务网页管理员密码独立修改，不改变设备图形和条目。设备没有忘记图形密码的App内恢复入口。

确实遗忘时，先确认服务网页能登录且完整列表可恢复，备份设备数据后再单独授权初始化设备管理凭据及本地缓存。不能在编译、源码同步或蓝牙修复时顺带清库，也不应重建身份或清空整个NVS。2026-10-09的PIN初始化和后来的旧PIN迁移均为历史操作，不重复执行。

现用服务中心加密导出扩展名为 `.ymvault`，导入仍要求对应部署身份；旧独立服务文档中的 `.jyvault` 为历史命名。加密导入的预览与去重合并不同于设备全量覆盖同步。Edge CSV仅用于网页分类，具体管理和部署以对应服务项目文档为准。

本工程保留的[PC说明](../server/pc.md)及[NAS说明](../server/nas.md)描述旧独立服务，不能据此启动第二份现用服务或覆盖服务中心数据。密码分区读取、内存和校验错误应分别处理，不能将失败当空库覆盖。
