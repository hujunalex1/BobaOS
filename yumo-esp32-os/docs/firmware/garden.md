# 萌芽物语

更新日期：2026-10-19。对应 2026-10-16 12:06:13（北京时间）成功烧录的紧凑状态栏版本，来源见[当前状态](../current-state.md)。

## 玩法与操作

一轮成长24回合，6条养成路线、12种形态；随机性状、天气、事件、培养方向和传承影响每轮体验。底部五个入口为照料、培养、冒险、家园和图鉴；操作图标、背景和宠物使用统一像素画风。宠物可点击，播放约1.2秒的互动效果，不因单纯点击消耗回合或写存档。

BOOT 单击执行当前页面“返回”：子页返回家园首页，图鉴详情返回图鉴，首页退出应用。BOOT 双击遵循系统返回主界面规则。KEY/PWR 保留普通系统行为；本应用不强制常亮。

## 当前界面

顶部信息框为188×45像素，高度由68像素缩短约三分之一，位于 x=48、y=4。首行组织宠物名称、成长阶段及果子/星星资产，第二行显示饱食、心情、体力数值与细进度条；成长阶段只显示文字，不显示成长数字比例。

萌芽、幼年、少年、成年使用不同名牌装饰效果。特效复用固定的非交互对象，熄屏停止更新。下方扩大宠物与场景区域，点击区域为184×135像素；操作控件与宠物互动区域分开，减少触控冲突。

## 数值结算与触控

一次有效回合先合并动作收益与回合消耗，再把饱食、心情、体力限制到0～100，避免先封顶再扣减导致收益不一致。每回合基础消耗为饱食4、心情2、体力3；训练、探索、记忆需要的体力分别为13、8、3。进入探索或记忆页面本身不重复扣回合，中间正确答案也不结算，完成后只结算一次。种植从0/4开始，再完成4个回合成熟；成年提示只在真正成长时出现。

保存由单个异步 worker 执行，最多排队8个待处理操作。保存回执更新状态，不重建正在触摸的页面；按住时延迟会销毁控件的操作。换页、重看、错误和退出清理尚未执行的操作，避免旧页面操作落入新页面。

## 记忆小游戏

演示前显示3、2、1倒计时，图案字号36像素，按钮86×70像素。单个高亮900毫秒、间隔300毫秒，演示期间禁用答题但保留图案清晰度。重看或重新进入从尚未回答的位置回放；关屏后唤醒重新倒计时，单帧推进上限100毫秒，避免一次跳过多个图案。

## SD 存档

卡根目录 `garden/` 由应用按需创建，内部挂载路径是 `/sdcard/garden`。`garden-a.sav` 与 `garden-b.sav` 交替保存，保留160字节的 `YMGARD01` 格式。两份记录应一起保留，不把备用记录当成重复文件删除。更新 SD 模板不得覆盖玩家已有存档。

读取校验格式、版本和完整性；可以从有效备用记录恢复，损坏或未来版本不会直接当作新档覆盖。保存使用修订号检测与幂等重试。首次保存尚无有效备用记录时仍有掉电风险；宿主文件回放不等于真实 SD 掉电保证。无卡可临时体验，退出不保存；拔卡前按系统流程安全弹出。

实现位于 `firmware/main/apps/garden.cpp`、`core/garden_model.*`、`core/garden_store.*`、`core/garden_service.*` 和 `ui/garden_scene.*`。配套回放为 `tooling/firmware/test_garden.py`、`test_garden_service.py`，画面资源生成器为 `generate_garden_art.py` 和 `generate_garden_controls.py`。已烧录来源完成构建及短时启动核验；长期游玩、全部路线实机体验和 SD 掉电仍需单独验收。
