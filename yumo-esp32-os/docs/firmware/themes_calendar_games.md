# 主题、时钟、万年历与小游戏

截至2026-10-14，以下功能已进入当前固件并烧录；本文于2026-10-15同步更新。版本、校验值及验证范围见[当前状态](../current-state.md)。屏幕为240×240，应用按需打开、退出销毁。

## 主题与开机画面

进入“设置→主题”，选择后确认保存并重启。系统先结束应用和存储工作，再保存主题；重启后 Wi-Fi 和蓝牙默认开启，分别尝试最近成功网络和最近配对设备，系统运动默认关闭。未设置或无效的主题编号使用默认10，不覆盖已有有效选择。

| 编号 | 名称 | 主要交互 |
| --- | --- | --- |
| 04 | 砂岩 | 暖色卡片、双列应用列表 |
| 05 | 墨线 | 浅色线框、双列应用列表 |
| 06 | 拼贴 | 桌面功能块与“全部应用”切换 |
| 08 | 一页 | 单项聚焦，滑动选择后打开 |
| 10 | 游标 | 带编号的纵向列表、游标与底部打开控制 |

应用顺序支持长按拖拽并保存，设置保持最后，独立深度睡眠App已移除；不同主题不强制使用相同布局。选项按下时反馈，释放后恢复；确实选中的主题、分页或游标保留选中状态，不因点击多个应用累计变暗。随机应用的内容展示随主题调整，八种模式和石头剪刀布PK的规则不变。

电脑演示入口是 [Open-Preview.cmd](../../desktop/ui-preview/Open-Preview.cmd)，当前同一个页面集中展示15套候选风格和每套三种基础表盘。固件只集成上表五套；HTML演示并非设备程序，也不代表新增黄历或小游戏已在演示页复刻。演示里的多个JS/CSS是同一页面依赖，不应按旧页面清理。

开机动画约1.2秒：线条绘出Y、圆点收拢、YUMO字样与短进度线显现，使用当前主题配色。只用几何图形和已有字体，不加载动画图片；结束删除定时器和对象。每次重启/深睡唤醒播放一次，普通亮灭屏不重播。

## 时钟

左右滑动循环切换数字、指针、混合、黄历四种表盘，全屏展示，无顶底切换按钮。

三种基础表盘分别适配五种主题。指针标识只写“YUMO”，不附主题编号；10号数字表盘没有“/RTC”，指针页左上日期、同排星期缩写，混合页左上为YUMO。04/05/06/08的布局按对应样例调整，简单日期采用英文星期及日期数字。混合及指针的刻度、指针和文字使用各自坐标，切换时清除旧布局状态，方向交给统一显示驱动。

黄历表盘五种主题共用布局，只更换配色：农历年月日、生肖、节气/节日、时辰、四柱八字、时星神、五行及中文时分秒。时辰与八字放在中间两行；只有发生变化的单字上下滚动替换，中文时分秒同样逐字更新。五行行根据当前时柱计算“天干:… 地支:… 纳音:…”，例如对应时柱可能显示“天干:阳火 地支:阳金 纳音:山下火”，不是固定文案。

中文时、分、秒均使用两位逐位数字：九分显示“零九分”，二十三时显示“二三时”，23:09:05 显示“二三时零九分零五秒”，00:00:00 显示“零零时零零分零零秒”。固定两位格式保留单字滚动；日期、农历及干支含义不变。休眠后的校准与学习精度边界见[网络校时](network_time.md)。

## 万年历

支持1901～2099年离线月历，显示公历、农历、节气和已收录节日。左右滑动或顶部箭头翻月；点击年月选择年月，点“今”回到设备当前日期。

点击某日进入手撕日历风格详情：大号日期在装订条与虚线之间居中，旁边显示星期、星座、节日或节气；下方显示农历干支年、生肖、农历月日和干支年月日。不显示旧的底部解释提示。五种主题只替换详情颜色，不改变布局。

计算使用中国民用时间UTC+8。黄历时钟按节气的具体时刻换年/月柱，八字日柱在23:00换日，民用日期与农历在00:00换日；日期详情不含具体时刻，按该民用日的节气日期计算，不借用次日的晚子日柱。两页在交节时刻附近可能有区别，这是当前采用的计算约定。设备时间不准时，应先到设置校时；月历范围比设置手动日期的2020～2099年范围更宽。

## 小恐龙

进入即显示叠在游戏场景上的菜单，背景保留恐龙、云、远山、近山和地面。点击“开始”后，触摸画面跳跃；左上暂停键打开游戏内菜单，可继续、重来或退出。碰撞后显示得分、最高分及再来一次；最高分持久化，游戏进行中定期检查保存，暂停/退出也保存变化。

云、山、地面石子使用不同像素轮廓和滚动速度。道具独立随机出现在平地或空中，地面20分、空中50分；不放在障碍正上方，并为已有和下一障碍预留跳跃距离禁区。障碍间隔按速度、完整跳跃时间及落地操作窗口计算，避免只按固定间距生成连续障碍。它是本地触控改编版，不承诺所有玩家在任何操作下都能通过。

菜单使用与场景一致的像素风按钮，点击菜单或菜单空白处不触发背后跳跃。关屏暂停，返回后手动继续；退出释放游戏界面、定时器、输入会话及音频任务。运行时有实时合成背景音乐和跳跃/加分/失败音效，不需要SD音频文件；音量使用系统音量。

## 重力迷宫

共15关，每3关提高迷宫维度：1～3关为5×5，4～6关为6×6，7～9关为7×7，10～12关为8×8，13～15关为9×9。倾斜设备控制小球，碰到圆环终点即通关，不计分。

触摸游戏画面打开暂停菜单。菜单直接叠在迷宫上，采用深色仪表面板、材质球徽章及五段难度进度条，与写实迷宫场景保持一致。可选关、开始/继续、重来、切换关卡或退出。过关后主按钮变成“下一关”，独立的“切换关卡”只切换所选关卡并停留菜单；第15关完成后可重新闯关，避免出现两个含义不清的“下一关”。

运行画面为按关卡生成的地面纹理、带高光/阴影的墙体、材质小球和圆环终点；不恢复类似乱码方框的地板装饰。钢球、石球、木球、胶球、玻璃球轮换，分别调整加速度、摩擦、速度上限和碰撞回弹，小球纹理随移动变化。菜单中文补入紧凑字库，动态数字及下拉箭头由已有数字/符号字体补齐。视觉调整保留原碰撞尺寸和碰触通关规则。

需先开启系统重力感应开关，游戏开始时获取临时采样需求，不改变开关偏好。进入整个迷宫应用即锁定当前屏幕方向，退出后恢复自动方向；操控按当前屏幕坐标映射。暂停、过关、关屏、退出释放临时需求；传感器数据不可用时回到菜单提示平放后重试。场景背景在开局/切关生成，运行时只更新小球及已有对象，不每帧创建控件。沙地降低速度，冰面更滑；落坑只位于非必经支路，落入后回到起点，必经路线保持可达。迷宫有独立合成音乐及材质滚动、碰撞、落坑、通关音效；暂停静音，退出释放音频及图像缓存。

## 设置中的设备信息

“关于设备”展示硬件、屏幕/音频/传感器、固件构建及标识、分区容量、运行时间、真实CPU频率、内部RAM/PSRAM、电池电压与估算电量、启动原因、无线及SD状态。分区容量不是剩余程序空间；SD状态也不等于已检测到物理插卡。

“系统与电源→系统信息浮层”提供前台应用、CPU频率/任务数、内部内存余量/最低值/最大连续块、PSRAM、界面刷新FPS/芯片温度、无线状态、服务忙闲/累计事件丢弃及运行时间。开启且亮屏时更新，关闭后停止采样；浮层不拦截触控。FPS是界面刷新率，不是CPU占用率或FC模拟帧率，静态画面低FPS不代表故障。

本版编译、源码及编译期模型检查通过，最新烧录后30秒启动检查通过；此前宿主LVGL布局/触摸结果按对应历史版本记录；实际触控手感、重力操控、长时游戏及功耗仍需设备体验。截图用法见[KEY双击截图](screenshot.md)。
