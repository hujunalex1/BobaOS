# 网速测速

本应用已纳入 2026-10-14 成功烧录版本；来源与验证范围见[当前状态](../current-state.md)。设备需连接可访问外网的 Wi-Fi，HTTPS 证书校验还需要合理的设备时间，可先进行[网络校时](network_time.md)。

## 界面与使用

进入“网速测速”开始测试，界面显示阶段、Wi-Fi、下载/上传速度和图表。下载与上传上下排列，数值紧跟各自文字，更多空间用于曲线。实时图保留 40 点；完成结果和历史详情按成功请求的原始样本绘制，缺失样本不伪装为零速，未获服务器确认的上传不算最终有效速度。

详情包含下载、上传、HTTP 延迟和 ICMP 网络质量数据，并记录网络与采样信息。测试中断、网络切换、断网、超时或数据不完整会保留原因；只连接 Wi-Fi 而无法访问测试节点时不能完成测试。

## 数据口径

当前已烧录实现使用 Cloudflare 的 `speed.cloudflare.com` HTTPS 下载/上传端点（`/__down`、`/__up`）。结果表示这台 ESP32 在当前省电设置、无线信号、路由及测试节点条件下的单连接 HTTPS 有效吞吐；不能直接作为宽带套餐上限、无线 PHY 速率或手机多连接测速结果。

| 数据 | 定义与范围 |
| --- | --- |
| 下载/上传平均速率 | 成功请求的总有效字节 × 8 ÷ 成功请求总耗时；不是各次速度的简单平均 |
| 单位 | 十进制 SI，Mbps 为百万 bit/s，MB 为百万字节；字节 × 8 ÷ 微秒可直接得到 Mbps |
| 完整性 | HTTP 200、请求完成且长度吻合；上传还需服务器确认字节数，失败样本不纳入速率 |
| 预热与采样 | 每方向先预热；目标有效传输 12 秒、最多 16 次请求、方向总时限 25 秒 |
| 充分性 | 至少 3 次成功、累计有效传输至少 10 秒且成功率至少 90% 才标为采样充分；不足时供参考 |
| 总预算 | 一轮最长 120 秒，payload 流量上限 32,000,000 字节，包含预热及部分传输；协议开销另计 |
| HTTP 延迟 | 10 次响应头等待时间，排除连接建立，仍包含请求传输与服务器处理；不是纯 ping |
| 延迟统计 | 均值、中位数、最近秩 P95、最小/最大；抖动为相邻成功样本的绝对差均值，失败会中断相邻关系 |

另用独立 ICMP 探测网关和 `1.1.1.1`：空闲各 20 次，下载与上传阶段各最多 48 次，每 500ms 发送、800ms 超时，payload 为 32 字节。比较空闲与负载时的延迟，帮助区分 Wi-Fi/网关问题和外网负载排队。

界面中的探测超时率不是已证实的网络丢包率：目标可能限速或禁用 ICMP；全无回复意味着该项无法测量，不单独断言网络断开。HTTP 与 ICMP 分别保留原始样本、成功/超时及错误信息，不混用两种延迟定义。

## SD 历史与删除

历史按设备日期时间和 Wi-Fi 名称（SSID）为标题，JSON 保存在卡根目录 `/speedtest/`，设备挂载路径为 `/sdcard/speedtest`。目录由应用按需创建，无须在模板中放空记录。文件名采用时间与独立标识，SSID 只保存为数据，不直接拼入路径。

记录包含设备时间/时区、是否已网络校时、SSID、BSSID/IP/信道、RSSI 起止及最小/最大值、节点 trace、用量、速度/延迟原始样本、置信信息和错误原因。历史标题的时间取决于当时设备时钟；尚未校时的时间不冒充网络确认时间。旧 schema 1 历史仍可读取。

历史详情最下方提供“删除此记录”，再次确认后删除选中记录。删除在后台持有 SD 修改权限，并核验卡代次与目标文件，避免列表刷新或换卡后误删其他记录。删除不可撤销。

无卡或写入失败不会提示已保存；保存采用临时文件、同步落盘和改名，具体结果以设备提示为准。退出取消任务并安全释放，拔卡、SD 忙和深睡收尾遵循系统存储会话规则。复制资源时保留已有 `/speedtest/` 数据；取卡前先完成写入并安全弹出。

## 结果解读与验证边界

“数据传输不完整”表示本次请求没有满足完整接收/长度或上传确认要求，不能把部分字节当作完整有效测速。失败计数、流量与诊断仍保留；网络差、服务器行为、连接中断等原因需结合具体错误和原始数据判断。

固件编译、源码契约以及生产 HTTP、采样调度、ICMP、存储和 UI 的宿主回放提供逻辑回归依据。图表、统计与保存不等于这台设备已经完成实验室吞吐校准；当前没有量化的实机速率精度或长期网络性能验收结论。比较不同测试时应保持节点、位置、供电/省电设置和其他客户端负载尽量一致。
