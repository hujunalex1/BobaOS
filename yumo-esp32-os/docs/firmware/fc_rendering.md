# FC画面输出与性能边界

更新至2026-10-22 18:24:55已烧录版本。NES原帧256×240，设备屏幕240×240；当前选取源图x=8～247、全部240行，一对一映射为RGB565并居中显示。左右各8列被裁切，无顶部/底部黑边，无拉伸、面积混色或缩放表。边缘HUD可能被裁切，这是点对点显示的取舍。

实时画面和读档预览共用`main/core/fc_video.hpp`；`scaleFrame`保留函数名但内部已是裁切和逐像素调色板转换。`fc_player.cpp`通过`lv_obj_center(image)`居中放置。

## 交替画面与显示调度

保留`fc_timing.hpp`的半速调度、奇偶相位切换及低频有界抖动，避免一直丢掉同一相位，导致交替闪现的数字、字母或精灵长期不可见。CPU/APU和输入推进仍以PAL 50Hz/NTSC 60Hz为目标，SPI显示发布上限约25/30fps；这是调度目标，不是当前整机实测帧率，也不是逐总线周期精确模拟。

这轮没有更换Mapper集合、存档格式或手柄控制。控制操作见[FC按键与手柄](fc_touch_controls.md)，ROM范围见[兼容说明](photo_fc_compatibility.md)。

## 已有验证和待确认项

真实Nofrendo PPU合成帧经过旧点采样、面积缩放和新1:1路径回放通过，包含相位调度、画面裁切和缓冲边界。来源电脑端7次样本中，300帧转换中位耗时从96,897μs降至5,993μs；这只衡量电脑上的像素转换，不代表ESP32游戏提升相同比例。

240×240比原240×225每帧像素数增加约6.7%；两个RGB565缓冲合计增加14,400字节。因此减少转换计算不等于SPI传输更少，不能据此保证所有游戏不卡顿。最新点对点版本已完成构建、烧录和启动校验；《加纳战机》道具、边缘HUD、实际流畅度和音画同步仍需用户实测。来源与本次同步验证见[当前状态](../current-state.md)。
