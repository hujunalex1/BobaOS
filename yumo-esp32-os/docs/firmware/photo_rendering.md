# 图片视口解码与SD缓存

更新日期：2026-10-20。当前JPEG/PNG查看采用流式读取、按当前视口输出和SD分块缓存；已纳入成功烧录版本。操作见[相册](reader_photo_random_20260921.md)，格式与FC边界见[兼容范围](photo_fc_compatibility.md)。

## 文件与内存边界

静态JPEG/PNG单文件上限16MiB（16,777,216字节），源边长上限16384像素、源像素上限64×1024²。上述为拒绝过大输入的保护边界，不保证所有边界内图片都能打开。损坏文件、未支持的编码、SD故障以及时间/内存不足仍会失败。

JPEG沿用libjpeg-turbo缩小解码、裁剪与跳行，保留适用情况下的快速回退；PNG流式逐行处理，支持既有透明黑底合成及Adam7。只为当前可见区域生成不超过240×240的RGB565显示帧，放大时改变源图采样区域，不把放大的整图放进RAM。小压缩文件最多缓存256KiB，大文件从SD读取；同一时刻的旧帧、新帧、解码器及缓存写入仍需额外内存。

渐进式JPEG的DCT系数仍取决于源图。当前可以把系数交换到SD的`.yumo-photo-cache-v1`目录，总交换预算128MiB，另保留工作内存和可用空间检查；最多64次扫描，解码协作超时180秒。交换文件与持久显示缓存用途不同；不能把屏幕仅240×240理解成任意图片解码成本相同。

## 缩放、拖动和复用

BOOT缩小、KEY放大，放大后可向上下左右拖动，最大到原图比例。快速连续操作合并为最新请求，过时任务取消；拖动时可先移动现有画面预览，新的视口准备好后再显示，失败保留当前有效图。

持久缓存目录为SD根目录`.yumo-photo-tiles-v1`。每个实际访问的缩放级别生成一个128×128 RGB565分块文件；同倍率下的所有平移位置共享它。命中后只读取视口需要的分块，回到已缓存倍率和再次打开图片可以复用。首次进入未缓存倍率仍需解码并生成该级别，不承诺首次操作与命中一样快。

每级缓存上限160MiB，持久缓存总预算256MiB、最多96项，要求保留16MiB空闲空间；按已有缓存时间清理旧项。检查源文件信息、缓存头和块校验，无效缓存不当成有效画面。临时写入成功并完成后才提交；缓存不可用时优先保留可用的解码结果，不为普通缓存失败拒绝显示。

两个缓存目录都可在退出相册、文件操作结束后清理；不会删除原图片，再次查看可重新生成。插拔SD先走安全弹出。异常掉电/拔卡、任意第三方篡改及真实SD性能仍需实测；不承诺固定打开耗时或拖动帧率。

GIF继续采用原有流式双帧播放，文件上限64MiB、源尺寸上限1024，不支持缩放，也不使用上述静态图缓存。

主要入口：`core/photo_loader.*`、`core/photo_frame_cache.*`、`core/photo_png.*`、`components/photo_jpeg/`及`apps/photo_viewer.*`。来源已完成流式解码、视口、缓存命中/损坏/取消与UI宿主回放；当前镜像成功烧录并启动，不能替代全部用户图片和SD卡实机验收。
