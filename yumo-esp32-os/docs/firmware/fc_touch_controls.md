# FC 本机控制、蓝牙键盘与手柄

工程：`.`，屏幕240×240。游戏仍放在SD卡 `/nes/`，进入“FC游戏”后直接点选游戏，无需先连接蓝牙。

## 游戏中的操作

| 位置 / 按键 | 功能 |
| --- | --- |
| KEY实体键 | A，按住持续生效，松开释放 |
| BOOT实体键 | B，支持连续点击，双击也不会退出游戏 |
| 屏幕下方左侧80×80区域 | Select / 选择，按下生效 |
| 屏幕下方中间80×80区域 | 打开游戏菜单并暂停 |
| 屏幕下方右侧80×80区域 | Start / 开始、确定，按下生效 |
| 屏幕左上120×120区域 | 固定虚拟摇杆，支持八方向，松手回中 |
| PWR单击 | 关屏并暂停；亮屏后在菜单中手动继续 |

游戏画面输出240×240居中1:1像素，原图256×240左右各裁8列，保留全部240行；边缘HUD可能被裁切。详见[画面输出](fc_rendering.md)。下方三个触区占据y=160～239，没有边框、文字或按压图案；仅左上摇杆半透明显示。摇杆中心固定在(33,33)，外圈左上坐标(0,0)贴屏幕左上角，外圈半径33（直径66），中间圆钮直径44、最大移动半径11。没有中心死区，触点偏离中心1像素即直接触发对应方向，支持八方向，不做渐进过渡；回到中心或松手即释放方向。拖动开始后一直归属原触区，滑到底部不会误按Start或打开菜单。

触屏按单个指针处理。操作摇杆时可同时按实体A/B，无需在小屏上同时触摸多个虚拟键。其余空白区域不触发游戏操作。游戏中不使用滑动返回，避免方向操作导致退出。

游戏菜单提供“继续游戏”“存档/读取”“返回游戏列表”“退出应用”，按钮高40px。存档页顶部为只读自动槽，下方三个手动槽，手动覆盖需确认；读档成功回暂停菜单，手动继续。详见[存档说明](fc_saves.md)。加载中也能取消并返回；退出等待模拟器任务收尾，再释放ROM、音频、画面和输入。加载、暂停及退出中的游戏不接收A/B。整个FC应用（含列表和蓝牙子页）禁用音量加减，退出后恢复。列表和蓝牙页保留BOOT双击返回主界面，游戏页及游戏菜单屏蔽它。

## 蓝牙键盘

应用内蓝牙设置可手动搜索、配对和连接BLE键盘/手柄，返回后停留在FC列表。已连接键盘沿用原映射：方向键移动、Z=A、X=B、Enter=Start、Tab=Select、Space暂停/继续、Esc停止并回游戏列表。

键盘方向和摇杆在同一轴冲突时，键盘方向优先。本机A/B和触屏Select/Start仍可操作。蓝牙断开会清除旧按键，本机控制可继续玩，不会因缺少键盘而拒绝运行；不自动搜索或重连。连接变化、暂停和亮屏恢复后，先松开原来按住的键，再重新按下，防止旧输入持续生效。

`/config/nes-keys.json`仍只配置蓝牙键位；固定的实体键和触区不受该文件影响。详细模板、ROM支持范围和性能边界见[SD媒体与FC说明](sd_media_fc_20260918.md)。

## IINE L1162手柄

C模式控制FC方向、A/B、Start/Select；H模式用于设备导航，方向选择可控元素、A确认、B返回，时钟左右翻页，不用H模式代替C模式玩FC。模式按不同蓝牙地址独立配对；当前安全绑定8个、同时一个连接。C模式方向/A/B已获用户确认，最新H模式修复仍待复测。

手柄连接且HID就绪时隐藏并禁用触屏摇杆，断开后恢复；连接变化清理旧输入，原来按住的键须先释放再重新按下。本机A/B和下方触区保留。详见[蓝牙连接](bluetooth_connections.md)。

## 重力方向

游戏列表顶部“重力 开/关”默认为关，本次App会话内有效。打开后，游戏以设备水平放置为中立，向左/右/上/下倾斜触发对应方向，斜向触发两个方向，摇杆圆钮同步显示最终操作方向。

| 系统运动开关 | FC重力开关 | 游戏行为 |
| --- | --- | --- |
| 关 | 关 | 不使用重力方向。 |
| 开 | 关 | 不使用重力方向，系统开关不自动开启游戏重力。 |
| 开 | 开 | 游戏运行时使用重力方向。 |
| 关 | 开 | 不产生重力输入，提示开启系统重力；不会绕过总开关。 |

暂停、关屏、打开存档页、回列表或退出会清理方向并释放FC的临时传感器需求；继续游戏重新获取。用户原有系统运动开关不会被FC关闭。触摸摇杆（包括按住中心）优先于重力，键盘在对应轴上优先于本机方向，实体A/B独立。

传感器固定水平参考，不自动把当前倾角校准为中立。采用0.10g进入/0.055g释放阈值及轻量滤波，过期超过150ms或异常幅值的样本释放方向并提示，不保留卡住的旧按键。

QMI8658已修正为±8g、自检关闭并回读寄存器，解决此前“感应不可用”的量程问题；临时采样验证16/16有效，诊断代码已移除。此前试验改造已由用户确认保留，无需按旧试验标记回滚。

## 实现与验证

实体键使用防抖后的PRESS_DOWN/UP，不等待单击或双击识别；按键归属带会话代次，旧任务不能修改新应用的输入。短促按下会保留至一个模拟帧，避免落在两帧之间被遗漏。按键回调只更新小型状态，不调用界面或访问ROM。暂停、关屏、换页、连接变化及退出清理输入，退出后尚未结束的旧单击/双击不转成音量或Home。

当前摇杆外圈66px、圆钮44px，中心(33,33)贴左上角，保留120×120触区与1px触摸方向响应。重力控制采用独立阈值；不要把它与无死区触摸混为一谈。当前控制、手柄与显示改动已纳入2026-10-22固件，构建与烧录详情见[当前状态](../current-state.md)。

用户已反馈此前FC改造效果良好并选择保留；具体ROM、全部输入组合、存读档触屏流程及音画性能仍需逐项实测。当前35种Mapper含24/74/245，范围见[兼容说明](photo_fc_compatibility.md)。
2026-10-20起，进入FC应用即锁定当前屏幕方向，包含列表和暂停菜单；退出后恢复系统自动方向。加速度映射至锁定后的屏幕坐标，详见[全屏方向](screen_orientation.md)。
