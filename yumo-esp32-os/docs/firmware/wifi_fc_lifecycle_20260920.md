# Wi-Fi、资源释放与FC蓝牙子页面

本页路径以工程根目录下的 `firmware/` 为起点。本文说明现有行为；构建、设备和服务状态以[项目当前状态](../current-state.md)为准。

## 当前资源管理

### 音频资源所有权

- 自有BSP记录扬声器、麦克风的device/codec/control/GPIO所有权，新增`bsp_audio_deinit()`。
- 先停止读写、关闭device，再删除codec及控制接口、I2S数据接口，最后按通道实际状态disable/delete TX/RX。仅删除成功才清空通道句柄；失败保留句柄以便下次重试。
- 初始化失败也走对应回滚；不再留下指向已删除通道的静态指针。初始化失败不会永久阻止后续再次打开音频。
- `Audio::closeStream()`在录音/FC后台任务收尾时回收上述资源；暂停关闭后再次继续会按需重建音频。同一录音文件的续录、文件头/fsync/close/rename规则不变。
- 空闲时调整音量只保留设置，不再为了音量设置创建I2S。开启Wi-Fi前尝试回收闲置音频；采用try-lock，遇到正在使用的流不等待、不强行关闭。
- 保留共享I2C总线，不能为了回收音频影响触控、时钟或其他器件。GUI线程不直接删除音频任务，不在持锁SD操作中强杀任务。

### Wi-Fi与系统请求

- 队列满使用独立`SystemService::QueueFull`错误，内存不足、处理中、超时分别提示。
- Wi-Fi开关提交后立即禁用触摸，系统层合并同一时刻的重复开关请求；命令执行完毕或入队失败后释放提交标记。
- 设置Wi-Fi页面和密码本网络页显示真实失败状态，内存不足不再等同于Wi-Fi已关闭/队列满。
- 仅启动失败时打印阶段、错误名、内部RAM总空闲和最大连续块，不打印SSID/密码，不新增常驻诊断任务或周期性堆日志。
- 早期音频释放修复未调整这些配置；后续Wi-Fi内存修复增加了LVGL渲染/GUI栈优先PSRAM路径，LCD DMA及关键控制块仍内部RAM，保留XiP保护。当前蓝牙修复未再改sdkconfig/defaults，不能套用旧内存配置回退。

### FC内蓝牙连接

入口：`FC游戏 → 蓝牙键盘设置`。不再启动设置App。

- 蓝牙子页顶部返回按钮和返回手势回到FC游戏列表；游戏现支持离线、本机A/B和虚拟摇杆，通过下方中间触区打开菜单，见[FC控制说明](fc_touch_controls.md)。
- 子页提供蓝牙开关、“已配对”“搜索”“断开/取消”。已配对列表仅显示键盘角色；附近列表允许选择可连接设备，由现有HID发现流程确认其是否为支持的BLE键盘。
- 已连接设备和列表项均使用统一身份组件：名称在上、地址小字在下。全局单连接规则不变；选择新的键盘目标时，由统一flow先断开电脑等旧目标，等真实收尾后再连接所选键盘。
- 默认不扫描，不自动重连；用户点搜索或已配对键盘时才发起操作，已配对回连继续使用原来的先扫描确认存在的流程。
- 等待后台执行不显示成已连接；配对交互仍由系统配对弹窗处理。
- 240×240布局，常用按钮高36px，设备行高42px；底部列表高86px，可完整显示两行并滚动。灰色普通按钮，蓝色开启/当前页状态。
- 触摸按住或滚动列表时冻结行身份，防止扫描更新把一次点击变成连接另一台设备。
- 离开蓝牙子页时取消用户扫描、释放列表缓存；本页发起但未完成的连接邀请也取消，已经建立的连接继续保留，用来回到FC玩游戏。

### 未完成连接的退出取消

新增不依赖命令队列容量的取消代次：退出时递增代次，系统线程在执行前后检查。旧代次尚未执行的连接请求不再生效；正在进行的广播/查找许可交还底层既有停止和超时流程收尾。新页面上的新手动请求使用新代次，不被旧退出误取消。

FC和密码本使用同一取消入口，解决退出时普通取消命令也可能因为队列满而丢失的问题。不会清绑定、不会deinit异步BLE栈，也不会为了释放App内存断开已经建立的连接。已进入GAP连接过程的取消仍需等原有回调/超时收尾，不能承诺GUI返回瞬间协议栈内存全部归零。

## 其他应用退出核对

| 应用 | 已核对的退出处理 |
| --- | --- |
| 录音机 | 停止/取消意图交给后台；保存文件、释放DSP/缓冲和音频；GUI定时器及列表销毁 |
| FC游戏 | 停止意图、解除键盘捕获、先drop图像缓存再释放像素；后台关闭音频、销毁模拟器/ROM/画面 |
| 蓝牙键鼠 | 取消排队按键、释放鼠标按下状态、停止自动点击、清组合输入和定时器 |
| 蓝牙音乐 | 删除界面状态定时器；此App是远端媒体键控制，不持有本地I2S音频流 |
| 文本、相册 | 取消读卡任务，后台当前I/O安全返回后回收；相册释放图片/解码资源，定时器销毁 |
| 时钟、重力迷宫 | 停止/删除刷新定时器；迷宫撤销临时传感器需求，时钟不再直接采样 |
| 手电筒 | 停止SOS、取消临时亮度、删除定时器和事件订阅 |
| 万年历、小恐龙 | 停止/删除定时器、注销订阅；小恐龙保存高分并释放按键会话 |
| 密码本 | 取消后台操作、释放解密会话、清敏感输入；退出连接邀请改用可靠取消入口 |
| 设置 | 删除定时器，取消用户扫描；保留系统级已连接无线状态 |

WindowManager继续单前台、按需创建，真正退出时销毁UI和App对象；没有预加载。普通PWR熄屏不是退出。系统BLE/Wi-Fi连接、触控、时钟和共享服务不是某个App的私有资源，不能为了“释放内存”盲目卸载。后台收尾与FreeRTOS任务删除可能比界面关闭晚一些，不能将此描述为所有RAM立即回到冷启动水平。

当前设置/密码本/FC使用同一BluetoothConnectionFlow，允许发现与已保存目标切换均等待旧GAP收尾，App取消仅作用于未完成请求。详见[蓝牙](bluetooth_connections.md)。用户已反馈Wi-Fi能成功连接，最新合成IDF回归见[当前状态](../current-state.md)，不等于所有AP及共存性能实测。

2026-10-31连接耗时修正：首次使用新鲜有效信道进行FAST扫描，失败后保留ALL扫描重试和既有生命周期隔离；蓝牙与省电策略未变。312个合成场景通过，已纳入11月2日成功烧录基线，详见[Wi-Fi连接耗时](wifi_connection_latency.md)。
