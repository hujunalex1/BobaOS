# 网页与设备修改密码

本页路径以工程根目录下的 `firmware/` 为起点。本文说明现有行为；构建、设备和服务状态以[项目当前状态](../current-state.md)为准。

## 服务端修改管理员密码

登录后点击页头“修改管理员密码”，依次填写原密码、新密码和再次输入的新密码。新密码4～128字符，允许中文；这只是网页管理员密码，与设备4～12位数字PIN彼此独立。

原密码正确且两次新密码一致才提交；提交成功后保留当前页面登录，其他会话失效。新密码使用新随机盐和原PBKDF2方案保存，密码库加密密钥、同步身份、加密包字节和版本不变。改密后登录与“展示密码”使用新密码。原密码错误显示原因并回到登录页；冷却机制保留。

三个输入框全部掩码，取消/Esc/页面后台/退出登录清空。保存期间禁止重复提交和取消，迟到响应不会重新打开已经退出的页面。数据库事务失败不会撤销既有会话；校验耗时期间若会话被撤销，不再写入新密码。没有新增依赖或后台任务。

## 设备修改数字密码

仅主分类页右上角显示“修改密码”，保留72×36触控面积；账号列表及用途等子页面不显示。关屏锁定仍保留。

流程：原数字密码 → 验证通过 → 新数字密码 → 再次新数字密码 → 保存成功提示并返回密码本分类首页。密码仍为4～12位数字。原密码错误、空/短/超长输入、确认不一致、取消及任务启动失败，均清空临时输入、提示失败并返回分类首页，不展示任何条目密码。

三步使用现有240×240全屏数字键盘，不恢复顶部状态栏或重置功能。提示和掩码共用21px一行，按键79×53px。空密码库也能修改PIN，无需先选一条密码。

校验、随机盐/KDF及Flash写入继续在按需worker执行，不阻塞GUI。最终保存再次验证磁盘中的原PIN，只修改本机配置的PIN盐/散列，保留密码包原字节、同步版本、地址及固定密钥。沿用非活动槽写入、校验后最后提交头的双槽机制。

关屏、退出应用和60秒空闲锁定仍保留，并清除超管/当前页明文授权；普通模式其他分类的单条密码仍30秒隐藏。关屏会撤销并脱离任务，迟到结果不会重新解锁。保存阶段不提供取消按钮；如果关屏/退出与最后一次Flash提交相撞，或提交后的读回校验失败，无法保证保存结果时会要求重新解锁，从磁盘确定真实PIN，避免旧内存配置覆盖已提交的新密码。此异常不应被误报为“修改成功”；重新打开时先用新密码核对。
