# Edge CSV导入

本页路径以工程根目录下的 `firmware/` 为起点。本文说明现有行为；构建、设备和服务状态以[项目当前状态](../current-state.md)为准。

## 使用

1. 手动启动Java服务并登录。更新Java源码后需重新构建JAR，再手动重启；参见服务端操作说明。
2. 登录服务端，进入“网页”分类的列表页面点击“导入 CSV”；其他分类不提供此入口。
3. 选择Edge导出的UTF-8 CSV文件，导入分类固定为“网页”，无需选择分类。
4. 点击“预览导入”，检查新增、合并更新、无变化数量以及最终名称、网址、备注。普通模式预览不展示密码，超管模式可展示；预览不写数据库。
5. 确认无误后点击“确认导入”，设备继续使用原来的“同步”按钮。无需为此修改设备固件。

## CSV与合并规则

支持 `name,url,username,password,note` 结构；`url,username,password` 必须存在，`name,note` 可省略。按列名读取，可调整列顺序；支持UTF-8 BOM、正常CSV引号、字段内逗号和空行。

- 先跳过空/纯空白账号，再跳过账号或密码含非可打印ASCII的行，并报告跳过原因和数量；其他格式错误仍需处理。
- 导入名称取 `username`，不使用CSV的 `name`；按账号忽略大小写、再精确比较排序，同账号的不同密码仍保留。
- 账号和密码都完全相同才合并，不忽略大小写，也不删除账号或密码中的空格。同账号不同密码分别保留。
- 新条目使用该组第一条完整URL，保留协议、端口、路径、查询和片段。
- 后续URL先取完整主机名或IP，去掉协议、端口、路径；域名转小写，国际化域名使用ASCII形式，再只保留前10字符，按首次出现去重加入备注，主URL的主机不重复追加。截断后相同片段只留一份。
- 原有备注优先，不同备注与额外域名片段用英文逗号拼接。单条备注最多256个UTF-8字节，超出只保留能容纳的前部，按字符边界截断且不留无内容分隔符；非域名的手工备注不适用10字符限制。重复导入不会反复追加已保留的同一备注/片段。
- 只匹配网页分类中的已有账号/密码，不改其他分类。后端拒绝非网页分类CSV请求。已有匹配条目保留ID、非空URL和备注；URL为空时补入第一条导入URL，追加缺失备注/域名，名称更新为账号名。不会自动清理历史上已经存在的多条重复记录。
- 所有有效变化一次事务保存，只增加一次同步版本；完全无变化时不写库、不增加版本。

## 限制与错误

为继续兼容现有设备，密码库总数最多256条。CSV最大128 KiB、最多4096数据行，允许大量重复行先合并；JSON上传请求上限1 MiB，其他接口原有小请求限制不变。

账号、密码仅支持可打印ASCII，密码最多128字符；账号要直接用作名称，因此本导入最多96字符且不能为空。首条完整URL最多192字节，最终备注最多256个UTF-8字节。域名/IP来源URL须为有效HTTP(S)地址，不能包含URL内嵌登录凭据；不访问这些URL。文字备注可以是中文，但控制字符/换行不符合现有设备格式。

无账号/不兼容字符行按上述规则报告后跳过，备注超长截去尾部；其他字段过长、URL无效、格式错误或超出总容量等显示错误行或原因，整批不写入，不截断账号/密码。最多展示20项错误，并提示总数。预览后若密码库发生变化，确认会被拒绝，需要重新预览，避免覆盖别人或其他页面的新修改。

普通模式预览、错误和日志不输出密码字段；超管会话预览可以展示密码。原CSV不持久保存到服务端，取消/锁定/离开可清除浏览器中的导入暂存。CSV本身为明文，成功导入并核对后请自行删除；原有可信局域网HTTP使用边界不变。
