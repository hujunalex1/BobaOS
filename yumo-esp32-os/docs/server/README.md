# 雨墨密码本 Java 服务端

Java 8 / Spring Boot 服务，业务与原工程一致。NAS使用用户提供的 `eclipse-temurin:8-jre`，运行时无需Maven、Python或外部数据库。

本仓库提供独立密码服务的源码、协议与部署模板，需要自行初始化配置、构建和手动启动；不附带预制NAS包。项目与验证边界见[当前状态](../current-state.md)。

## 功能

首次设置服务管理员，至少4字符；无默认密码，与设备密码本的九点图形密码独立。普通模式的工作/应用/网页密码隐藏，单条展示需再次验证，30秒后隐藏；其他类码值在登录后持续明文且不显示账号；可修改管理员密码。空闲5分钟锁定，登录会话最长30分钟。

最多256条，名称96字节、用途192字节、备注256 UTF-8字节；账号/密码最多128个可打印ASCII，符合设备蓝牙输入范围。工作先按单位/系统分组，应用先按应用名称/平台分组，网页先展示账号再展示用途；其他直接展示码值条目；同账号不同密码全部保留，列表每页40项。新建/编辑的推荐密码按钮填入推荐密码，位数可设（默认 16 位，4–64），并可勾选大写/小写/数字/符号字符类型，浏览器本地生成，保存才写入。

“超管模式”重新验证服务管理员后，在列表、详情、编辑和CSV/加密归档预览中明文展示。退出超管、锁定、登出、离开页面或会话撤销会清除权限和明文；不持久保存管理员密码或超管状态。

网页分类独享Edge CSV导入：UTF-8/BOM、128KiB/4096数据行，表头需要url、username、password。忽略空账号和蓝牙不支持的字符行并报告；名称取账号，同账号密码合并，已有非空用途URL优先，否则保留首个完整URL。后续域名去重、每个最多10字符后逗号加入备注；单条备注256字节，尾部截去且保持UTF-8边界。其他格式错误仍阻止整批提交。预览/导入按账号排序，确认有版本冲突校验。

所有分类支持加密 `.jyvault` 导出及去重合并导入（256KiB/256条）。服务端导入是合并；设备点击同步则完整覆盖设备列表，包括删除及有效空列表，二者不能混淆。

## 同步、存储与升级

同步密钥分别配置在 `server/vault-sync-key.properties` 和 `firmware/vault-sync-key.properties`，两端须保持一致；修改后重新构建并交付两端。每次首次克隆初始化生成独立的新密钥。同步鉴权与本地存储身份分离；只更换同步密钥不能重生成原存储身份或擦除设备密码区。协议详见[PROTOCOL](PROTOCOL.md)。

从根目录运行 `Build-Server.cmd`，默认联网解析依赖、执行测试并打包。启动脚本直接使用 `artifacts/server/joyvault.jar`，不再额外维护另一份pc/JAR。升级正在运行的本副本时，先正常停止，再构建和验证，最后手动启动；不能边运行边覆盖JAR。具体步骤见[本机运行](pc.md)与[构建说明](../build.md)。

SQLite采用原有单连接、目录独占锁、事务同步和失败回滚。数据不放在容器可写层，NAS通过独立硬盘目录挂载 `/data`。升级保留固定身份和数据目录，同一数据库只运行一个服务实例。

HTTP测试使用隔离目录和合成数据；浏览器测试需要本机Edge或显式配置浏览器路径。源码、协议检查、Windows测试都不替代NAS实机长期运行验证。本副本不升级框架或改变Java8兼容要求。

2026-10-19已部署的分类更新已纳入本次源码同步：详情和编辑属性名称统一；工作/应用新建或编辑可下拉复用已有分组，也可手动输入新分组。其他类账号字段保留兼容存储但不显示，普通元数据响应包含码值。对应139项Java、117项浏览器、91项HTTP检查为来源部署验证，本轮未重启服务或打包NAS。
