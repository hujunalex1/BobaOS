# 回归测试数据

`contracts/`只存当前回归检查实际读取的局部代码基准、协议/配置校验值和电量样本。它们是测试输入，不参与固件构建，也不能作为项目备份恢复。原始内容保持以便发现行为回归；不包含用户密码库、部署密钥、旧固件或整套历史任务目录。

`superseded-contracts.json`保留原有45项过期检查的替代说明，本次未新增排除。构建、源代码和分区边界仍由当前检查验证。

运行`Build.cmd`会生成本目录的构建配置、编译固件，并执行源码及编译期检查。源码检查也可单独运行`tools/run_source_checks.py`；它需要已有构建配置中的分区表和烧录清单。
