# 雨墨 SD 卡目录总说明

本目录是设备使用的 SD 卡资源模板。把这里需要的**子目录直接复制到 SD 卡根目录**，不要再套一层 `resources`、`sdcard` 或 `joycode`。设备内部的 `/sdcard` 是挂载路径，不是需要在卡上创建的文件夹。

## 模板现有目录

| 目录 | 对应功能 | 放置内容与使用方式 |
| --- | --- | --- |
| `config/` | 密码本同步、FC 按键配置 | `vault.json` 设置密码服务地址；`nes-keys.json` 设置蓝牙键盘游戏映射。两份文件均可手动编辑，保持 JSON 格式。 |
| `nes/` | FC 游戏 | 放入自行准备且有权使用的 `.nes` 游戏。模板为空，不含游戏 ROM。设备也会在这里生成手动和自动存档。 |
| `recordings/` | 录音机 | 设备生成录音 WAV 文件，按录音时间命名。模板为空；设备写入过程中可能出现 `.wav.part`，正常停止后完成保存。 |
| `chiptune/` | 8Bit 音乐 | 使用 `*.chip.json` 乐谱，设备合成播放。已附公版旋律的重新编曲及原创示例；曲目及格式说明见本目录内的 `曲目与使用说明.txt`。不能用 MP3、MIDI 或游戏 ROM 直接替代。 |
| `programming/` | 编程速查 | `library.ykb` 是设备读取的知识包。设备会生成 `state.bin` 保存阅读与收藏状态。 |
| `patterns/` | 设计模式游戏 | `lessons.ypg` 是设备读取的关卡包。设备会生成 `progress.dat` 保存进度。 |

`nes/`、`recordings/` 仅含目录说明，复制时也应保留，方便直接复制使用。更新教学资源时，保留卡上已有的 `state.bin`、`progress.dat`。模板仅放置设备资源、配置和说明文档；电脑端教学源码及构建校验资料不放在此目录中。

## 密码本同步地址

编辑 `config/vault.json` 的 `url`，填写电脑或 NAS 在局域网内的地址及实际映射端口，例如：

```json
{
  "schema": 1,
  "url": "http://vault.local:8443"
}
```

地址只是示例，应改为实际地址；保持 `schema` 为 `1`，仅保留这两个字段，不添加接口路径、账号、密码或密钥。当前 SD 配置采用 `http://地址:端口`。

密码本先使用设备已保存的连接配置同步；失败后按界面提示尝试读取此文件。只有新地址同步成功后才更新设备本地配置。密码库不放在此文件或 SD 卡资源目录中，双端同步密钥也不从 SD 卡读取。

## FC 按键与存档

`config/nes-keys.json` 的默认映射：方向键控制方向，`Z` 为 A，`X` 为 B，`Tab` 为选择，`Enter` 为开始，`Space` 为暂停，`Escape` 为退出。修改时保留现有字段结构，使用固件支持的键名。

设备提供三个手动存档槽和一个独立自动存档槽。存档写入 `nes/`，文件名以 `ym-` 开头、以 `.sav` 结尾；自动存档名包含 `auto`。同一槽的 `a/b` 文件是交替写入的保护机制，应一起保留，不要当成重复备份删除。

## 使用时另行创建的目录与文件

以下目录未预放在当前模板中：

| 建议目录或文件 | 用途 |
| --- | --- |
| `MP3/` | 自行创建，只扫描本层`*.mp3`，同名`.lrc`/`.LRC`用于歌词；不包含音乐资源。见[MP3音乐](../../docs/firmware/mp3_music.md)。 |
| `garden/` | 萌芽物语自动创建；`garden-a.sav`、`garden-b.sav` 交替存档，两份均需保留；无卡体验不保存。见[游戏说明](../../docs/firmware/garden.md)。 |
| `speedtest/` | 网速测速自动保存 JSON 历史；标题为设备时间和 Wi-Fi 名称，详情底部可确认删除。复制模板时保留已有记录，详见[测速说明](../../docs/firmware/speed_test.md)。 |
| `screenshots/` | 设备截图时自动创建，按截图时间保存 PNG；可在相册中查看。 |
| `txt/` | 可自行创建，用来归放文本。文本应用可以浏览 SD 卡目录，不限定必须叫 `txt`；支持 `.txt`、`.md`、`.log`、`.csv`。 |
| `photos/` | 可自行创建，用来归放图片；目录名可自定。相册支持 JPEG、PNG、GIF，GIF 可全屏播放。 |
| 文本同目录下的 `.yumo-read-*.bin` | 设备自动生成的阅读进度文件，跟随对应文本目录保留。 |

## 复制与取卡

- 第一次使用可复制整套模板；已有录音、存档和阅读记录时，按需合并资源，避免用空目录或电脑旧文件覆盖卡上数据。
- 编辑配置或添加资源后，在相应应用中刷新或重新进入。
- 在设备的“设置 → 系统与电源”执行“安全弹出 SD 卡”，完成后再取卡；录音、存档或其他文件写入过程中不要拔卡。
- 本说明可随资源一起复制，也可仅留在电脑端；固件不依赖本说明文件。
