以当前设备为边界，不用电脑特效代替可落地的 UI。

显示与图形

依据本项目的 ESP32-S3、240×240 SPI LCD、RGB565 和 LVGL 软件绘制配置。只使用色块、圆、直线、固定刻度；移除屏内模糊、滤镜、阴影、渐变网格与连续装饰旋转。图标已准备小尺寸 PNG 位图，不要求固件支持 SVG 解码。

字体与密度

中文标题、说明改为已有 16px；应用名保留专用 14px。ASCII 数字仅使用已开启的字号，大号字、很小的中文不再照搬。时钟使用真实固件字形位图；其他页面用浏览器字体近似排版，选定后仍须核验 LVGL 字宽与图标资源。

触控与输入

所有操作可单指点击、滚动或滑动，不要求多指、悬停或实体旋钮。常用按钮至少 36×36；网络输入框 36px，两行共享输入器各 54px。轨道改为点选确认，Wi-Fi 与蓝牙子页在全部风格中复用同一实现。

更新与资源

一次只创建当前主题的预览，切换主题卸载上一组界面和录音状态。滚出视口的样例不持续刷新。多屏仅用于网页比较，设备仍按需打开一个 App，不要求后台运行。LCD 深色不等于背光省电；这里不是实机性能验收。

本页全为虚构数据，不访问 Wi-Fi、蓝牙、麦克风、SD 卡或密码服务。未详细设计的 App 保留入口并明确提示；随机的 04、05、06、08、10 已对应固件布局；其余主题仅供比较。网页输入使用浏览器输入框，设备仍复用系统键盘。演示不代替实机验收。
