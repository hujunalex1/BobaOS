# CubePaw 功能候选清单

日期：2026-11-18 · 只做方案，不改代码

## 0. 先看结论

CubePaw 现在有 16 个注册应用，底层沿用 Yumo OS 的成熟能力；源码里另有 12 个已编译但未注册的模块（随机、8Bit 音乐、手电筒、FC、摩斯等），可以低成本复活。

硬件边界决定了哪些想法现在能做：

| 能力 | 现状 | 对功能的含义 |
| --- | --- | --- |
| 屏幕 | 1.54 寸 240×240 触摸 | 适合大按钮、单屏小游戏；不适合复杂表格/多窗口 |
| IMU | QMI8658 六轴 | 体感游戏、摇一摇、抬腕/静止检测都能做 |
| 音频 | ES7210 双麦 + ES8311 喇叭 | 录音、变声、音效、故事、语音留言都能做 |
| 网络 | 2.4G WiFi + BLE 5 | 天气、AI、家长网页、局域网留言；离开 WiFi 要能降级 |
| 存储 | 可选 Micro-SD | 作品、故事、音乐、存档都依赖 SD；没卡时要优雅提示 |
| 缺失 | 无摄像头、无 GPS、无振动马达、无电池 RTC | 不能做拍照/定位/离线闹钟级可靠提醒；提醒只能靠声音+屏幕 |

我的判断：下一步最值得做的不是“再加一个工具”，而是三条线——

1. **创造力出口**：画画、变声、音乐。孩子能产出自己的东西，才会反复玩。
2. **成长闭环**：星星/徽章/每日任务，把现有 16 个应用串成一个“我的手表”。
3. **家长价值**：一个局域网家长页，解决使用时长、找手表、传内容三件事。这是家长愿意买单的部分。

## 2. 第一梯队：两周内能看到东西

### 2.1 画画波波

- **做什么**：240×240 画布，12 色蜡笔、3 档笔刷、橡皮、撤销、清空、6 个印章（草莓/星星/爱心/爪印/彩虹/波波球）。作品存成 PNG，相册里直接能看；后续可一键设为表盘。
- **硬件/接口**：CST816S 触摸（LVGL indev）、SD 卡。无需网络。
- **改动点**：
  - 新增 `apps/doodle.cpp/.hpp`，按 `ui::App` 生命周期实现。
  - `main.cpp::register_apps` 注册；`firmware/main/CMakeLists.txt` 加入源文件。
  - `core/sd_media.hpp` 增加作品目录（如 `/sdcard/pictures/doodle`）。
  - 复用 `core/screenshot_png.h` 的 `screenshot_png_write()` 把 canvas 像素写成 PNG；SD 读写走 `core::sd::Session`。
  - UI 用 `ui/compact_ui` + `ui/theme`，工具栏做大按钮（至少 44px）。
- **工作量**：3–5 人日 + 1 天美术/手感调优。
- **参考**：LVGL canvas 示例；`core/screenshot.cpp` 的 PNG 写入和 SD 会话；`apps/photo_viewer.cpp` 的图片列表。
- **风险**：1.54 寸画布小，笔刷要粗、工具栏要少；撤销至少留 2 帧（约 230KB，放 PSRAM）；保存时处理 SD 弹出。

### 2.2 声音泡泡

- **做什么**：录 3–10 秒，播放时变声：花栗鼠、低沉怪兽、机器人、回声、慢放；另加 8 个搞怪音效按钮（掌声、笑声、动物、魔法、弹簧）。可以连续按出节奏。
- **硬件/接口**：ES7210 麦克风、ES8311 喇叭、SD。
- **改动点**：
  - 新增 `apps/voice_lab.cpp/.hpp`；复用 `core/audio_recorder.*` 的 WAV 读写和 `core/audio_mgr.*` 的流接口。
  - 新增 `core/voice_effect.*`：变速/变调优先用“改变播放采样率”实现（`Audio::openStream(false, rate)`），机器人用环形调制，回声用短延迟缓冲。
  - 音效可用 `core/chiptune_player` 实时合成，或放几段短 WAV。
  - 录音目录沿用 `/sdcard/recordings`，文件命名加 `voice-` 前缀。
- **工作量**：5–8 人日。
- **参考**：`apps/recorder.cpp` 的录音/回放；`core/recorder_dsp` 里已有 speex 重采样；`audio_mgr.openStream(rate)` 直接改采样率就能做出“花栗鼠/低沉”。
- **风险**：音频是独占资源，要和 MP3、小智、游戏音效互斥；变声质量先求“好玩”不求“专业”；音量要做限幅，保护听力。

### 2.3 星星罐

- **做什么**：跨应用成就系统。首批 15 个徽章：连续照顾萌芽 3 天、恐龙跑 500 分、迷宫过 5 关、画画 10 张、口算 20 题、连续 7 天开机……解锁贴纸、表盘边框、首页小装饰。首页显示“今日星星”，点进去是徽章墙。
- **硬件/接口**：无新增；NVS + SD。
- **改动点**：
  - 新增 `core/rewards.*`：规则表、计数、解锁状态、存档校验；NVS 只存小计数，批量提交沿用 `core/settings_store` 的 worker 模式。
  - `ui/window_mgr.*` 发布“应用打开/关闭”事件；各游戏在结算处调用 `rewards::award()`。
  - 新增 `apps/achievements.cpp/.hpp` 徽章墙；`ui/home_screen.cpp` 加星星入口/红点。
  - 贴纸/边框先用现有 emoji/矢量资源，别等新美术。
- **工作量**：7–10 人日 + 美术。
- **参考**：`core/garden_model.hpp` 的固定长度校验存档；`apps/dino.cpp` 的最高分持久化；`settings_store` 的批量 NVS 提交。
- **风险**：规则太多会变成 KPI；先做 12–15 个，确保每个都能在 3 天内达成；避免每帧写 NVS。

### 2.4 照片表盘

- **做什么**：从相册选一张照片，滑动/缩放裁剪成 240×240，叠加时间日期，保存为第 4 个表盘。可以放家人、宠物、自己画的画。
- **硬件/接口**：SD、触摸。
- **改动点**：
  - `apps/watchface.*` 增加 `Photo` 表盘类型；`core/photo_loader.*` 已有 `targetWidth/panX/panY`，直接复用。
  - `core/settings_store.*` 存照片路径和裁剪参数；SD 不在时回退到默认表盘。
  - `apps/photo_viewer.*` 增加“设为表盘”按钮。
- **工作量**：2–3 人日。
- **参考**：`apps/watchface.hpp` 现有 3 个 face 的切换；`core/photo_loader.hpp`；`ui/cute_clock.cpp` 的时间叠层。
- **风险**：大图解码内存；SD 拔出后的回退；照片只存本地，不上传。

### 2.5 家长小助手（非游戏，但最值得做）

- **做什么**：手机连同一 WiFi，打开手表 IP 的网页（4 位 PIN）：今天/近 7 天各应用使用时长；设置每日总时长和 Bedtime；一键“找手表”（响铃 + 闪屏）；上传 MP3/故事/照片到 SD；允许/隐藏某些应用。
- **硬件/接口**：WiFi、喇叭、屏幕、SD。
- **改动点**：
  - 新增 `core/parent_portal.*`（HTTP 页面 + JSON API），可参考 `core/config_server.cpp` 的表单页和 `core/lan_web.cpp` 的会话/PIN 模式。
  - 新增 `core/usage_log.*`：`WindowManager` 记录前台应用和屏幕开关时间，按天汇总，低频落盘。
  - `core/power_mgr.*` / `WindowManager` 执行时长限制和 Bedtime 锁；锁屏用可爱的“该休息啦”页面，不是错误弹窗。
  - 文件上传走 multipart，限制类型/大小，写入 SD 前检查剩余空间；与“安全弹出 SD”互斥。
  - `apps/settings_*` 增加入口，显示网页地址和 PIN。
- **工作量**：12–18 人日。
- **参考**：`core/config_server.*`、`core/lan_web.*`、`apps/speed_test.cpp` 的 HTTP 服务端/客户端、`apps/file_manager.cpp` 的 SD 操作。
- **风险**：只做局域网，不暴露公网；PIN + 会话超时；上传要防路径穿越；限时功能要考虑“充电时是否豁免”；家长页的文案要能让非技术家长看懂。

## 3. 第二梯队：有明确玩法，需要一到两周

### 3.1 晚安波波

- **做什么**：故事列表（SD 故事包）+ 15/30 分钟睡眠定时 + 雨声/篝火/白噪音 + 屏幕渐暗 + 结束“晚安”动画。后续可接 AI 现编故事。
- **硬件/接口**：喇叭、SD、屏幕；WiFi 可选。
- **改动点**：新增 `apps/night.*`；`core/ambient.*` 合成环境声；复用 `core/mp3_player` 或 `audio_mgr`；`core/sd_media.hpp` 增加 `/sdcard/stories`；`power_policy` 用 `StayLit|LowLoad`，播放结束自动熄屏；家长页上传故事。
- **工作量**：6–10 人日（离线版）；AI 版再加 6–8 人日。
- **参考**：`apps/mp3_music.cpp` 的列表/暂停/歌词；`core/chiptune_player` 的实时合成；`core/power_policy.hpp`。
- **风险**：故事包版权（用公版/自制）；夜间播放耗电；音频独占。

### 3.2 节奏波波

- **做什么**：6 个彩色打击垫，内置 3 首儿歌节奏谱；跟拍评分；可录 8 小节循环，叠加鼓点。
- **硬件/接口**：触摸、喇叭。
- **改动点**：新增 `apps/rhythm.*` + `core/synth.*`（方波/噪声/包络）；扩展 `core/chiptune_score` 支持实时音符；`audio_mgr` 低延迟输出；音量限幅。
- **工作量**：7–11 人日。
- **参考**：`core/chiptune_player.*`、`resources/sdcard/chiptune` 的乐谱格式；`apps/dino.cpp` 的音效。
- **风险**：I2S 缓冲带来的延迟会影响手感，需要真机调；儿歌版权；听力保护。

### 3.3 动动波波

- **做什么**：3 个 60 秒体感小游戏：摇摇赛车（倾斜换道）、钓鱼（抬腕收杆）、接水果（左右倾斜）。结算给星星。
- **硬件/接口**：QMI8658、触摸、喇叭。
- **改动点**：新增 `apps/motion_arcade.*`；用 `Qmi8658::claimTemporaryUse()` 拿前台租约；复用 `apps/gravity_maze.cpp` 的倾斜映射和校准；复用 `apps/dino.cpp` 的游戏循环/碰撞/音效；`powerHints` 声明 `LowLoad`。
- **工作量**：8–12 人日（3 个一起）。
- **参考**：`apps/gravity_maze.cpp`、`ui/home_screen.cpp` 的波波物理、`apps/dino.cpp`。
- **风险**：每个孩子手腕方向不同，需要“当前姿势校准”；久玩耗电；屏幕小，操作必须一键能懂。

### 3.4 聪明波波

- **做什么**：3 个模式：20 以内加减、乘法口诀、识字卡（拼音+组词）。10 题一局，连击/星星/音效；家长页看正确率。
- **硬件/接口**：触摸、喇叭（可选 TTS）。
- **改动点**：新增 `apps/quiz.*` + `core/quiz_model.*`；题库内置或放 SD；`rewards` 联动；家长页统计。
- **工作量**：5–8 人日 + 内容。
- **参考**：`apps/tetris.cpp`/`dino` 的结算 UI；`apps/text_reader.cpp` 的字体/分页；`apps/garden.cpp` 的小游戏交互。
- **风险**：题库质量；识字卡发音需要 TTS 或录音包；别做成“刷题机”，一局要短。

### 3.5 今日任务

- **做什么**：家长在网页布置 3 件事（刷牙、喝水、整理书包），手表上打勾；完成得星星；连续 7 天有徽章；睡前提醒未完成。
- **硬件/接口**：WiFi 可选；NVS/SD。
- **改动点**：新增 `core/tasks.*`；家长页表单；首页/表盘显示进度；`rewards` 联动；提醒用声音+弹窗。
- **工作量**：7–10 人日（依赖家长小助手）。
- **参考**：`core/garden_model` 的状态机；`core/config_server` 表单。
- **风险**：家长配置成本；提醒太吵；离线时用本地默认任务。

## 4. 第三梯队：亮点大，但先别急

### 4.1 家庭信箱

- **做什么**：家长在网页按住说话，留言到手表；孩子按一下播放，可以回一条。只在家庭 WiFi 内，不上云。
- **硬件/接口**：WiFi、麦克风、喇叭、SD。
- **改动点**：新增 `core/family_box.*` + HTTP 上传/下载 + WAV 编码；手表录音复用 `core/audio_recorder`；首页红点/提示音；浏览器用 AudioWorklet 录 WAV（避开 webm 容器解析）。
- **工作量**：15–22 人日。
- **参考**：`core/config_server`、`core/lan_web` 的会话、`apps/recorder.cpp`。
- **风险**：隐私与安全（PIN、局域网、可选加密）；存储清理；浏览器兼容性。比“找手表”复杂一个量级，建议二期。

### 4.2 AI 故事口袋

- **做什么**：选“恐龙/太空/公主/勇敢”等主题，生成 1–3 分钟故事并朗读；或“为什么”问答。
- **硬件/接口**：WiFi、喇叭。
- **改动点**：新增 `apps/story_ai.*`；优先验证 `core/xiaozhi_transport.hpp` 的 `sendText()` 能否让已绑定 agent 返回 TTS；否则用 DeepSeek 生成文本 + 小智 TTS；加预设提示词和内容安全过滤；家长开关。
- **工作量**：8–12 人日 + 云服务。
- **参考**：`core/xiaozhi_service.*`、`core/xiaozhi_transport.*`、`core/deepseek_client.*`。
- **风险**：依赖第三方、延迟/计费、内容安全、离线不可用。先把“离线故事包”做稳，再考虑 AI 现编。

## 5. 零成本/快速复活

源码里已经编译但没注册的模块，注册即用；适合填空档：

| 模块 | 现状 | 工作量 | 注意 |
| --- | --- | --- | --- |
| 随机（骰子/石头剪刀布/转盘） | `apps/randomizer.*` 完整 | 1–2 人日（注册 + 摇一摇） | 很适合儿童；摇一摇用 IMU 租约 |
| 8Bit 音乐 | `apps/chiptune.*` 完整 | 1–2 人日 + 乐谱 | 需要 SD 乐谱；可内置几首公版曲 |
| 手电筒 | `apps/flashlight.*` 完整 | 0.5 人日 | 儿童喜欢；注意误开耗电 |
| FC 游戏 | `apps/fc_player.*` 完整 | 2–3 人日 + ROM | ROM 版权风险，不建议默认内置 |
| 摩斯电码 | `apps/morse.*` 完整 | 1 人日 | 偏大童/学习，放二级页 |

这些不是“新功能”，但能让应用抽屉立刻更丰富，适合在等待大功能时先上。

## 6. 不建议做/暂缓

- **摄像头、视频、GPS/定位**：硬件没有，别用软件绕。
- **开放社交/好友/聊天室**：儿童产品，没有账号体系和审核能力，风险大于价值。
- **常驻唤醒词**：ESP32-S3 能做，但耗电、误唤醒、隐私都难解释；小智现在是手动按键说话，够用。
- **AI 生图**：成本、内容安全、没有摄像头，暂时不划算。
- **广告/内购/外链**：不适合儿童手表。
- **深度睡眠定时闹钟**：现在深睡只支持 PWR 双击唤醒，没有电池 RTC；要做可靠闹钟得改唤醒源并接受功耗，先做“充电/待机时闹钟”更稳。

## 7. 建议排期

**第一波（约 2 周，先把“好玩”做出来）**

1. 画画波波（3–5 天）
2. 声音泡泡（5–8 天）
3. 照片表盘（2–3 天，可与画画共用图片管线）
4. 星星罐先做骨架：记录 + 5 个徽章（3–4 天），后续再加徽章

**第二波（约 3–4 周，补产品完整度）**

5. 家长小助手（12–18 天）
6. 晚安波波（6–10 天）
7. 节奏波波或动动波波（二选一，7–12 天）
8. 今日任务（跟随家长页，7–10 天）

**第三波（验证后再投）**

9. 家庭信箱（15–22 天）
10. AI 故事口袋（8–12 天，先做技术验证）

## 8. 实现约定（新应用都要遵守）

- 应用继承 `ui::App`，实现 `onCreate/onShow/onHide/onDestroy`；不要在别的线程碰 LVGL。
- 声明 `powerHints()`：常亮/低负载/可调暗；阅读、画画、音乐、游戏按需声明，别让系统在玩的时候熄屏。
- SD 读写一律走 `core::sd::Access` / `core::sd::Session`，处理拔卡、弹出、USB 读卡器模式。
- 音频走 `core::audio_mgr`，和 MP3/小智/录音互斥；退出时释放。
- 设置写 NVS 走 `core::settings_store` 的批量提交，不要每帧写。
- UI 用 `ui/theme` + `ui/compact_ui`，适配现有 5 套主题；新图标先用 `LV_SYMBOL_*`，别急着改字体。
- 注册应用只改 `main.cpp::register_apps` 和 `CMakeLists.txt`；应用顺序由 `core/app_order_model` 管理。

## 9. 如果只能做三件

1. **画画波波**：最低成本带来“这是我的作品”的成就感。
2. **声音泡泡**：最能体现“手表不只是小手机”，孩子会拿去逗家人。
3. **星星罐**：把已有应用串起来，决定孩子第二天还愿不愿意打开。

家长小助手不算“孩子吸引力”，但它是让家长放心、愿意持续给孩子用的关键；建议和第二波一起做。
